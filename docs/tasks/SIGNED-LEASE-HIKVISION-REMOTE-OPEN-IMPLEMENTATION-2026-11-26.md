# 已确认签约后的海康远程开门

日期：2026-11-26，Asia/Shanghai。起点：`d798be60b2968a46cac22b6a5cdb25acc5e7b467`。本文件登记本次开发范围与接线要求；不表示已部署、已连接设备或已完成验收。

## 已确认的业务流程

手机号经微信服务端核验并注册/复用住户 → 服务端记录已确认签约事实 → 自动取得对应房屋、门禁与租期的远程开门资格 → 有效租期内可由本人点击远程开门 → 后续另行上传人脸，开通刷脸通行。

签约确认与资格写入属于同一事务，不新增租客申请或门禁二次审批。注册本身不新增房屋或门禁权限；照片、人脸任务、押金和第三方支付不是远程开门前置。自动取得资格不自动发出开门指令。

本次提供的是**已确认签约事实的可信录入及消费接口**。管理员须依据实际已确认的合同录入住户、房屋、租期及签约证据引用；点击该入口不生成签名、不代替实际签约、不裁定合同法律生效时点。正式合同生成、电子签署供应商、法律及费用政策仍按各自既有边界处理。

## 服务端事实与权限

新增独立云函数 `signedLeaseAccess`。住户身份来自可信 WX APPID/OPENID、规范身份索引与私有手机号核验记录，不采信客户端自报 userId、手机号、签约状态、房号、门号或租期。管理员操作来自既有后台认证/角色/CSRF校验，普通住户、editor及viewer不能配置或确认合同。

房产ID沿用 `rooms.houseId`，不是出租listing的 `houses._id`。绑定配置按房产ID查询，要求当时唯一，再在事务内点读固定room文档并保存其引用；后续签约与派发复核同一文档及房产ID。现有其它rooms写者未纳入本模块，不能把配置时唯一性查询描述为全库唯一索引已部署。

服务端保存：已确认签约租期、自动资格、本人资格索引、房产到门的绑定、派发配置、worker认证哈希、单次指令与审计。资格不写回 `users.houses`，也不沿用旧public/admin捷径。

日期采用明确填写的上海日期：起租日00:00:00计入，最后租赁日计入；内部上界为次日00:00:00且不计入。无需人脸即可在此租期内24小时点击远程开门。缺日期或无效日期失败关闭，不补今天、一年或长期有效。

## 一次开门的阶段

1. 租客提交服务端给出的合同标识及本次requestId，服务端事务重读签约、本人、租期、门绑定和开关，创建短时命令与审计。
2. 受控局域网worker使用独立身份领取属于其设备的命令。领取不表示设备执行。
3. 执行前服务端再次事务复核，CAS推进到executing；旧合同revision、撤销、换门、缩租、关开关或到期均不能继续。
4. worker先核对同一快照、本地明确设备映射与允许门号，受限读取公开证书并实读型号，再取得最后一次begin许可；本地再次核时后执行固定普通open。不接受云任务传入URL、XML、凭据或常开/常闭命令。
传输层另带不可延长的absoluteDeadline：每次发送、TLS/pin通过后放行socket前及Digest认证重发均受同一任务/租期上界约束，不能让相对timeout在慢握手后重新延长权限。未传该可选参数的旧调用保留原超时行为；不更改CR-2冻结文件。

5. 回报设备协议确认、拒绝或未知。HTTP 200本身不能当作成功；协议接受指令也不等于门锁物理释放或本人现场通行成功。

requestId持久去重；同一资格限制并行在途命令。事务回调重试不得发设备请求。超时、崩溃、授权回执未知或设备结果未知不自动重发、不重新入队。已执行命令的未知结果需人工核查后显式处置，不把该异常处置变成正常开门前的第二次审批。

撤销或到期阻止新的授权及尚未开始的指令；不承诺撤销已发送到设备的物理动作。一次业务open可能含Digest首发及401后的认证重发，不能把逻辑调用数写成TCP连接数或HTTP发送数。

后台另提供admin-only只读记录查询，可核对合同、门绑定、worker脱敏记录、程序开关及任务的当前revision；缺失返回null，不猜默认值，不自动提交或启用开关。住户端使用服务端原始起止日期显示租期，不依赖设备时区重算。

worker提供显式`--execute-once`与`--execute-loop`模式，后者出站轮询新任务、同一时刻只处理一条；默认命令不执行。轮询不重排或重发旧指令；未知与正常排队、设备协议接受分别显示。
