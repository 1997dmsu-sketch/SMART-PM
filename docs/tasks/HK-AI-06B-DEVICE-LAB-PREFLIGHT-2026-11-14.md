### 0.3 证据层级、候选端点与结论枚举

沿用 06A 的三级证据；本卡只增加“现场证据记录”格式，不提升任何已有证据等级。

| 层级 | 含义 | 本卡状态 |

| L1 文档存在 | 06A 已核验的公开官方页面/项目内官方摘要 | 27/27 候选端点有文档摘要；**不等于目标设备支持** |

**候选端点规则：**

1. 06A 的 27 个端点在本文中一律是 `candidateOnly=true`、`allowedNow=false` 的**候选**。
2. 只有目标设备在获批只读检查中实际返回、且经复核的记录，才可能把对应项写成 `confirmed`。
3. 文档存在、产品族页面、近似型号、Mock 行为、HTTP 200、销售口述都不能升级为 `confirmed`。
4. `unsupported` 只用于设备明确返回“不支持”/字段明确缺失；读不到、看不懂、超时、权限不足一律 `unknown`。

| 结论 | 定义 | 最低证据 |
|---|---|---|
| `confirmed` | 在该完整型号 + 该固件上直接观察到，可复核，无冲突 | 脱敏请求/响应摘要 + 采集时间 + 操作人占位 + 复核人 |

| `unknown` | 默认值；证据不足、冲突、不可读、未执行 | 记录“为什么未知”和下一步 |

## 1. 门禁模型、审批与职责

### 1.1 五道门 G0–G4

5. 停止不需要批准；任何人发现第 8 节条件都可立即触发 kill switch。

### 1.4 默认关闭与 kill switch

初始状态一律为：

```text
allowDeviceOperations = false
phase1ReadOnlyApproved = false
phase2WriteApproved = false
eventTrustApproved = false
providerReleaseApproved = false
```

Kill switch 可由现场执行人、见证人、网络安全、电气负责人、隐私负责人**无审批**触发，方式至少包括：

1. 按物理急停/切断适配器输入；
2. 断开测试电脑与设备的网线/禁用交换机端口；
3. 撤销当前审批单（记录 `revokedAt`）；
4. 停止抓包、关闭回调端口、禁用临时测试账号；
5. 将设备标记为“隔离封存”，禁止归还/上线。

Kill switch 触发后，未完成的测试不得自动续跑；恢复必须重新走对应门。

- 扫描局域网、网段、端口或使用发现类工具；
- 调用未在审批单中列出的设备 API；
- 创建真实人员、上传真实人脸、使用真实员工/访客生物特征；
- 使用真实 IP、MAC、序列号、账号、密码、Cookie、Token、私钥；
- 连接生产网、生产 Wi-Fi、生产 VPN、生产门禁控制器或云平台；

> 对应 06A：Q01、Q02、Q03、Q08、Q09、Q11、Q12，以及 Q05/Q06 的身份前置。

### 2.1 完整型号与硬件版本

必须做“三源对照”，而不是只看一个页面：

| 来源 | 记录内容 | 脱敏要求 | 冲突处理 |
|---|---|---|---|
| 设备铭牌/包装 | 完整型号、全部后缀、硬件版本、输入电压/电流/极性、区域标识 | 序列号/二维码/条形码/MAC 全部遮挡，只留末 2 位或 `<MASKED-*>` | 与系统信息不一致 → S01 |
| Web 管理页“系统信息” | 型号、固件、硬件、序列号（脱敏）、区域 | 截图裁掉序列号/二维码；日志不落原始值 | 与铭牌不一致 → S01 |
| 只读 `deviceInfo`（若 G1 批准） | `model`、`firmwareVersion`、`firmwareReleasedDate`、`hardwareVersion` | 响应只存摘要；序列号/MAC 掩码 | 与上两者不一致 → S01 |

**判定规则：**

- 只有“完整型号 + 全部后缀”与审批单一致，才允许进入后续步骤；`DS-K1T671BM` 与 `DS-K1T671BM-3XFTD`、`DS-K1T671B`、`DS-K1T671M(D)` 等**不能互相替代**。
- 铭牌磨损、后缀看不清、包装与机身不一致、区域版本不明 → 一律 S01 停止，不用“大概是”补齐。
- 硬件版本与固件 build 必须成对记录；只记“最新版”不算证据。

### 2.2 固件版本、build 与区域

| 字段 | 来源 | 记录方式 | 备注 |
|---|---|---|---|
| `firmwareVersion` | 系统信息 / `deviceInfo` | 原样字符串（版本号本身可公开） | 不写“约等于” |
| `firmwareReleasedDate` / build | 系统信息 / 厂商书面 | 日期 + build | 缺一不可 |
| `hardwareVersion` | 铭牌 / 系统信息 | 原样 | 与固件成对 |
| 区域版本 | 铭牌/系统信息/厂商书面 | 枚举或原文 | 区域不同不能外推 |
| 指南/固件对应关系 | 厂商书面 | 文档编号 + 页码/条目 | 销售口述不算 |

**禁止外推：**

- 不用 `DS-K1T671M(D)/MW(D)/MG(D)` 的公开固件/手册证明裸 `BM`；
- 不用 `DS-K1T671BM-3XFTD` 的测温指南证明裸 `BM`；

- 未取得铭牌 + 系统信息 + 厂商书面三者之一时，`firmware` 保持 `unknown`。

### 2.3 capability 页面与只读确认

G1 只读阶段允许查看 Web 管理页的 capability/系统信息页面，并在单独批准下读取 06A 候选端点。所有端点均为**候选**，不是已验证能力。

| 能力门 | 06A 候选端点（`candidateOnly=true`） | 只读字段 | 缺失/`false`/冲突 |
|---|---|---|---|
| 设备身份 | `GET /ISAPI/System/deviceInfo` | `model`、`firmwareVersion`、`firmwareReleasedDate`、`hardwareVersion` | 不建立身份基线；S01 |
| 人员总能力 | `GET /ISAPI/AccessControl/capabilities` | `isSupportUserInfo`、`isSupportFDLib`、`isSupportUserInfoDetailDelete`、`EmployeeNoInfo.*` | 禁止人员/人脸/删除写 |
| 人员操作能力 | `GET /ISAPI/AccessControl/UserInfo/capabilities?format=json` | `supportFunction`、`maxRecordNum`、`UserInfoSearchCond.maxResults`、`EmployeeNoList.maxSize` | 禁止对应操作；不写死 100/56 |
| 人脸能力 | `GET /ISAPI/Intelligent/FDLib/capabilities?format=json` | `supportFunction`、`FDRecordDataMaxNum` | 禁止人脸写；不推断容量 |
| 人脸库 | `GET /ISAPI/Intelligent/FDLib?format=json` | `FDID`、`faceLibType` | 禁止写；不写死 `FDID=1` |
| 系统/事件 | `GET /ISAPI/System/capabilities` | `isSupportSubscribeEvent` | 不建立事件订阅 |

**规则：**

1. `supportFunction` 必须逐操作判断（`get/setUp/post/put/delete` 分别看），不能用“总能力 true”替代具体操作。
2. capability 页面显示“支持”不等于目标固件实际可写；必须以目标设备、目标固件、实际返回为准。
3. Web 页面与只读 API 冲突 → S06，停止写测试，记录冲突，不“选一个相信”。
4. 读不到 capability 时，对应能力保持 `unknown`；不能按“默认支持”继续。
5. 本卡**不调用**上述任何端点；它们只是 G1 的候选检查项。

### 2.4 MAC / 序列号：仅脱敏

| 标识 | 仓库/日志/截图/抓包中允许的形式 | 禁止 |
|---|---|---|
| MAC | `<MASKED-MAC>` 或仅末 2 位；不作为设备主键 | 完整 MAC、OUI + 完整后缀、可反推的哈希 |
| 序列号 | `<MASKED-SERIAL>` 或仅末 2 位 | 完整序列号、二维码原图、包装条码原图 |
| 设备主键 | 内部 `deviceRef`（随机/工单号） | 用 MAC/序列号当 `deviceRef` |
| 原始照片 | 仅现场加密介质；脱敏副本入证据包 | 原图进仓库、聊天工具、云盘、邮件 |
| 屏幕截图 | 裁剪/遮挡后再截；关闭通知和账号信息 | 截到完整序列号、MAC、二维码、账号 |

**脱敏顺序：** 先关通知/退出账号 → 再裁剪/遮挡 → 再截图 → 去 EXIF → 计算 SHA-256 → 双人复核 → 才允许离开现场介质。任何一步做不到，就不采集该画面。

| 平台接入密钥、证书、私钥、License 文件 | 移除或仅导出证书主题/指纹 | 不导出 |
| 人员、卡号、人脸、指纹、密码、组织 | 全部清空或仅导出空结构 | 不导出 |
| 门权限、权限计划、特殊模板 | 仅导出字段名/结构，不导出现场值 | 不导出 |
| 网络参数、Wi-Fi、VPN、代理、DNS | 用占位符替换；不导出真实地址 | 不导出 |
| 设备位置、楼层、联系人、邮箱/短信 | 删除或掩码 | 不导出 |
| 日志、事件、抓包、审计 | 先脱敏再导出；不导原始载荷 | 不导出 |
| 设备证书/自签证书 | 只记主题/颁发者/指纹/有效期 | 不导出私钥 |

**导出流程：**

1. 在隔离网络内导出，不接生产网、不接云。
2. 导出前再次确认“人员/人脸/凭据/密钥”四类为零；否则停止。
3. 导出到加密离线介质（双人保管），计算 SHA-256，登记证据包清单。
4. 导出后做敏感扫描：完整 IP/MAC/序列号/账号/密码/Token/私钥/人脸路径零命中。
5. 仓库只保留“脱敏后的字段清单/差异摘要/哈希”，**不提交原始配置文件**。
6. 导出介质按第 7.4 节留存/销毁；不进入代码仓库、聊天工具、云盘。

### 2.6 身份证据的结论写法

| 场景 | 结论 |
|---|---|
| 铭牌、系统信息、`deviceInfo` 三者一致，固件/build/硬件齐全 | 可写 `confirmed`（仅限该设备/该固件） |
| 设备明确返回某能力不支持 | `unsupported` |
| 只看到 Web 页面、没读到 API；或字段缺失/冲突 | `unknown` |
| 只看到近似型号/公开页面 | `unknown`，不得写 `confirmed` |

## 3. 隔离网络、测试电脑、防火墙、抓包与时间

> 对应 06A：Q05、Q06、Q07、Q22、Q25、Q32。

### 3.1 拓扑与隔离要求

| 要求 | 必须 | 禁止 |
|---|---|---|
| 网络 | 独立 VLAN 或独立交换机；物理/逻辑隔离 | 接生产 VLAN、生产交换机、生产路由器 |
| 上联 | 无上联；无默认路由；无 NAT 到生产/公网 | 通过生产网做远程支持、云绑定、固件在线升级 |
| 地址 | 测试电脑固定地址；设备地址由网络负责人分配 | 生产 DHCP、生产 DNS、跨网段扫描 |
| 无线 | 测试电脑 Wi-Fi 关闭；不使用生产 Wi-Fi | 手机热点、访客 Wi-Fi、蓝牙共享网络 |
| 设备 | 单台设备、单台测试电脑、单条链路 | 多设备互连、接生产门禁控制器 |
| 标识 | 端口/线缆/设备贴“联调专用，禁止上线” | 无标识混用 |

**“禁止生产网”的核验方式：**

- 核对交换机端口 VLAN、上联、ACL、DHCP snooping/防环配置；
- 核对测试电脑路由表无默认路由、无生产 DNS 后缀、无 VPN 虚拟网卡；
- 核对设备网络状态页的网关/DNS/NTP 均为测试占位值；
- **不做** ping 扫描、端口扫描、网段探测、ARP 扫描或任何发现类操作。

发现任何生产上联、生产 VLAN、生产 DHCP/DNS、生产设备或云连接 → **S03**，立即断开，不抓生产流量。

### 3.2 测试电脑固定地址占位方案

| 项目 | 占位符 | 规则 |
|---|---|---|
| 测试电脑地址 | `<TEST-PC-IP>` | 网络负责人书面分配；静态配置；不写进仓库 |
| 子网前缀 | `<PREFIX-LENGTH>` | 与设备同隔离网段；最小可用范围 |
| 设备地址 | `<DEVICE-IP>` | 由网络负责人分配；不写进仓库 |
| 网关 | `<GATEWAY>` | 隔离网段网关；无生产出口 |
| DNS | `<DNS-SERVER>` | 仅测试 DNS 或留空；不使用生产 DNS |
| NTP | `<NTP-SERVER>` | 隔离网内时间源；见 3.5 |
| 抓包点 | `<CAPTURE-POINT>` | 测试电脑本地或隔离交换机镜像口 |
| 事件回调端口 | `<CALLBACK-PORT>` | 仅 W6 批准时开放；默认关闭 |

**测试电脑加固：**

1. 仅保留一个有线网卡；Wi-Fi、蓝牙、蜂窝、VPN、虚拟网卡全部禁用。
2. 不使用 Internet 连接共享/网桥；不装抓包以外的代理/远控。
3. 主机防火墙默认拒绝入站；出站仅放行 3.3 的允许项。
4. 专用浏览器配置：无扩展、无密码保存、无自动填充、无云同步；用完清理缓存。
5. 磁盘加密、屏幕锁、USB 自动运行关闭；不使用生产账号登录。
6. 地址、账号、拓扑的真实值只放**密封附件/工单**，仓库与本文只保留占位符。

### 3.3 防火墙允许项（默认拒绝）

| 方向 | 源 | 目的 | 端口/协议 | 用途 | 默认 |
|---|---|---|---|---|---|
| 出站 | 测试电脑 | 设备 | TCP 443 | HTTPS 管理/只读 | 允许（G1 批准后） |
| 出站 | 测试电脑 | 设备 | TCP 80 | 仅 443 不可用且单独批准 | 默认拒绝 |
| 出站 | 测试电脑 | NTP | UDP 123 | 时间同步 | 允许（指向 `<NTP-SERVER>`） |
| 入站 | 设备 | 测试电脑 | TCP `<CALLBACK-PORT>` | 仅 W6 事件回调 | 默认拒绝 |
| 任意 | 任意 | 任意 | 任意 | 其他 | **拒绝** |

**明确禁止：** SMB/135/139/445、RDP/3389、UPnP/SSDP、mDNS/LLMNR、Telnet/23、FTP/20/21、设备主动访问 Internet、测试电脑访问生产网。防火墙规则导出时也按 2.5 脱敏。

### 3.4 TLS、HTTP 与 Digest 的只读观察

| 项目 | 记录 | 不做什么 |
|---|---|---|
| HTTPS 端口 | 实际端口、是否可协商 | 不尝试降级到 HTTP |
| 证书 | 主题、颁发者、有效期、SHA-256 指纹、是否自签 | 不导出私钥；不把自签证书装进生产信任库 |
| TLS | 协议版本、密码套件（只读） | 不跑漏洞扫描/密码爆破 |
| 401 语义 | `WWW-Authenticate` 的 scheme/algorithm/qop/realm 摘要 | 不记录密码；不做离线破解 |
| 时钟偏差 | 响应 `Date` 与测试电脑时间差 | 不用偏差绕过认证 |
| 自签 | 仅隔离实验、单独批准、临时信任 | 不写“生产可用” |

**规则：**

- 认证方式、算法、qop 只做“观察记录”，不据此判断“安全”或“可上线”。
- 任何需要真实管理员密码、共享账号、默认密码的登录 → **S05**，停止。
- HTTP 明文仅限隔离实验且单独批准；不得传输真实凭据；抓包中的认证头按秘密处理。

### 3.5 时间同步

| 项目 | 方案 | 证据 |
|---|---|---|
| 时区 | 设备与测试电脑统一 `Asia/Shanghai`（或书面批准的其他时区） | 时间页截图（脱敏） |
| 时间源 | 隔离网 `<NTP-SERVER>`；无外网 NTP | NTP 配置页 + 同步状态 |
| 同步前/后偏差 | 记录 `offsetBeforeMs` / `offsetAfterMs` | 测试电脑与设备时间页 |
| 预检阈值 | 内部门禁建议 `abs(offset) ≤ 5 s`；**不是厂商值** | 超阈值 → S12 |
| 事件时间窗 | 06A 的 5 分钟仅为内部提案，**不是厂商能力** | 事件样本 + 厂商书面 |
| 无 NTP 时 | 手动校时 + 书面批准 + 记录校时前后值 | 审批单 + 截图 |

**规则：**

- 设备时间不可信时，不能仅凭设备 `dateTime` 做事件判断；必须同时记录测试电脑接收时间。
- 事件时间、时区、夏令时、时钟漂移均记 `unknown`，直到现场样本和 NTP 证据齐全。
- 时间偏差未解决，不进入 W6/W7。

### 3.6 抓包、日志留存与访问

| 项目 | 规则 |
|---|---|
| 抓包点 | 测试电脑本地或隔离交换机镜像口；不接生产镜像口 |
| 过滤 | 仅 `<TEST-PC-IP>` ↔ `<DEVICE-IP>`；不抓其他主机 |
| 格式 | pcapng，保留时间戳、接口、方向；记录工具版本 |
| 内容 | TLS 下不解密；HTTP 下认证头/ Cookie 视为秘密，分享前删除 |
| 存储 | 加密离线介质；访问双人；登记哈希 |
| 留存 | 建议：复审结束后 30 天销毁；最终由安全/隐私书面批准 |
| 日志 | 设备日志、Web 操作日志、测试电脑系统日志均先脱敏再导出 |
| 共享 | 只共享脱敏摘要/哈希；不共享原始 pcap、原始配置、原始截图 |

**抓包前必须确认：** 隔离完成、无生产流量、审批单包含抓包范围、存储介质已加密、销毁责任人已指定。发现生产流量混入 → S03，立即停止并删除该段抓包（记录事件，不分析生产内容）。

## 4. 电气、安装与急停

> 对应 06A：Q01、Q32、Q33 中的现场安全部分。

### 4.1 铭牌、电压、电流与极性核实

| 检查 | 证据 | 通过条件 | 不通过 |
|---|---|---|---|
| 设备铭牌 | 正反面脱敏照片 | 完整型号、输入电压、电流、极性符号、制造商信息清晰 | 铭牌缺失/磨损/型号不符 → S01/S02 |
| 适配器铭牌 | 脱敏照片 | 输入/输出、电压、电流、极性、认证标志清晰 | 适配器与设备不匹配 → S02 |
| 电压 | 铭牌 + 适配器 | 明确标注 DC 12V（或设备铭牌明确的其他值） | 不是 DC 12V 或标注不清 → S02 |
| 电流 | 铭牌额定电流 | 限流 ≤ 铭牌额定值；保险丝匹配 | 超额定/无标识 → S02 |
| 极性 | 铭牌极性符号 + 插头标识 | 内正外负/标记清晰可辨 | 极性不明/反接风险 → S02 |
| 接口 | 设备端子/插头 | 与适配器匹配；无改装 | 改装/飞线/裸线 → S02 |

**硬规则：**

> **只有在铭牌明确标注 DC 12V 且极性符号可辨后，才允许在断电状态下用万用表核对 DC 12V/GND 与插头极性。** 不得凭线色、旧文档、经验、销售口述或“同系列都这样”推断。

### 4.2 断电检查与首次上电

**断电检查（LOTO）：**

1. 拔掉适配器交流输入与设备端 DC 插头；挂牌“禁止合闸”。
2. 确认设备所有 LED 熄灭；等待至少 30 秒。
3. 万用表确认适配器输出为 0 V；核对插头极性/通断；确认无短路。
4. 检查端子无松动、无金属异物、无液体、无裸露导体。
5. 由电气负责人复核并签字。

**首次上电：**

1. 使用有认证的适配器/实验电源；**不直接接市电**；不飞线、不改装。
2. 限流设为 ≤ 铭牌额定电流；保险丝匹配；急停可达。
3. 设备保持独立：不接电锁、消防门磁、生产门、出门按钮、门禁控制器。
4. 上电后观察启动、告警、异味、发热、异常重启；异常 → S09。
5. 记录上电时间、电流/电压（若表可读）、启动结果、操作人占位。

### 4.3 不接电锁、消防门磁、生产门

**本卡及 G1/G2 全程禁止：**

- 连接任何电锁、磁力锁、电插锁、灵性锁；
- 连接消防门磁、消防联动、火警信号；
- 连接生产门、生产门禁控制器、出门按钮、门状态传感器；
- 用继电器输出驱动任何真实负载；
- 把设备安装在真实出入口或生产通道。

门权限测试只验证“逻辑门号/权限计划/查询结果”，**不验证物理开锁**；继电器端子保持不接。

### 4.4 急停与断电恢复

| 项目 | 要求 | 证据 |
|---|---|---|
| 急停位置 | 操作员伸手可及；标签“急停/切断设备电源” | 脱敏照片 |
| 急停范围 | 切断适配器交流输入（不是只断 DC 输出） | 接线图 + 实测 |
| 急停预试 | 上电前用假负载/空载测试，确认能切断 | 测试记录 |
| 人员 | 一人守急停，一人操作设备；不独自作业 | 审批单 |
| 断电恢复 | 切断 → 等待 ≥30 秒 → 确认无残压 → 限流上电 → 观察启动 → 重做只读基线 | 恢复记录 |
| 自动恢复 | 禁止自动续跑测试/自动重启业务 | 配置与记录 |

**断电恢复后必须：**

- 重新确认型号/固件/时间/网络未被改变；
- 重新跑 R1–R6 只读基线（若 G1 仍有效）；
- 未重新审批，不继续任何 W 测试；
- 记录断电原因、时长、恢复结果、是否触发 S09。

### 4.5 接线前后脱敏照片模板

| 照片 ID | 时机 | 角度/内容 | 必须展示 | 必须遮挡 | 元数据 |
|---|---|---|---|---|---|
| `PH-BEFORE-01` | 接线前 | 工作台全景 | 设备、适配器、急停、端子、线缆 | 序列号、MAC、二维码、位置/门牌、屏幕、人脸 | 去 EXIF，SHA-256 |
| `PH-BEFORE-02` | 接线前 | 端子/插头特写 | DC 12V/GND 标识、极性、线色 | 序列号、二维码、背景可识别信息 | 去 EXIF，SHA-256 |
| `PH-AFTER-01` | 接线后 | 与 BEFORE-01 同角度 | 接线路径、端子固定、无外接负载 | 同上 | 去 EXIF，SHA-256 |
| `PH-AFTER-02` | 接线后 | 端子/插头特写 | 极性正确、无飞线、无电锁/门磁 | 同上 | 去 EXIF，SHA-256 |
| `PH-ESTOP-01` | 上电前 | 急停/切断点 | 标签、可达性、切断范围 | 位置/门牌/人员面部 | 去 EXIF，SHA-256 |

**照片规则：**

- 先遮挡/裁剪再拍，或拍后立即脱敏；原图只留加密离线介质。
- 不拍人脸、不拍工牌、不拍门牌/楼层/房间号、不拍生产设备。
- 不把照片发聊天工具/云盘；证据包只放脱敏副本 + 哈希。
- 照片不能替代电表读数；电压/极性仍需万用表记录。

### 4.6 异常与热管理

- 上电后至少观察一个完整启动周期 + 10 分钟稳态；记录表面温度（如有测温工具）。
- 不堵塞散热孔；不放在软垫/密闭箱；环境温度符合厂商要求。
- 出现异味、变色、异常烫手、风扇异响、反复重启、告警灯 → 立即急停/断电 → S09。
- 不“再试一次”排除偶发重启；不复位、不升级固件、不恢复出厂。

## 5. 第一阶段：只读确认（规划，0 执行）

> 对应 06A：Q04–Q09、Q11、Q22、Q25、Q31 的只读部分。第一阶段**只读**，不写、不建、不传、不授权、不订阅。

### 5.1 G1 准入条件

全部满足才允许开始 R1–R6：

8. 回滚步骤 RB-01–RB-09 已预演或可执行；kill switch 明确。

**R6 特别说明：** 如果设备页面没有明确“ISAPI 版本”字段，不得猜测、不得用固件号代替、不得写“支持某版本”；记录 `unknown` 和“页面无此字段/需厂商书面”。

### 5.3 只读操作规范

- 只用 `GET`/页面浏览；**禁止** POST/PUT/PATCH/DELETE、表单提交、配置保存、重启、恢复出厂、固件升级、云绑定。
- 一次只开一个会话；不并行多标签操作；不点“测试”“诊断”“一键配置”等可能产生副作用的按钮。
- 只读账号权限最小化；不保存密码；不使用浏览器自动填充；操作后清缓存。
- 请求/响应只记**摘要**：方法、路径、状态码、字段名、值（脱敏）、时间；不存原始 XML/JSON 全文。
- 截图先遮挡序列号/MAC/二维码/账号/位置；日志不落完整 URL 中的敏感查询参数。
- 任何页面提示“需要管理员/需要密码/需要云账号” → S05，停止。

### 5.4 第一阶段退出标准

| 条件 | 要求 |
|---|---|
| R1–R6 记录 | 6/6 有记录；每项结论为 `confirmed`/`unsupported`/`unknown` 之一 |
| 身份基线 | 完整型号、硬件、固件、build、区域齐全且三源一致 |

**即使 6/6 完成，也不自动进入 G2。** 任何关键项 `unknown`（型号、固件、capability、删除/权限语义），不得进入写测试。

**目的：** 确认目标设备/固件是否具备可验证的事件身份、签名、nonce/时间窗、重传标识和重复处理语义，为 G3 事件信任决策提供证据。

**审批门禁：**

1. 安全负责人 + 厂商支持 + 项目负责人三方书面批准；见证人在场。

3. 由厂商/安全在独立授权下执行；06B 不执行、不提供步骤。
4. 任何“需要攻击/绕过/伪造”的动作一律不在本卡范围；如审批要求包含此类动作，退回重审。

**可接受的证据：**

| 证据项 | 可接受 | 不可接受 |
|---|---|---|
| 厂商书面说明 | 签名/nonce/时间窗/重放保护的明确声明 + 文档编号/页码 | 销售口述、聊天截图 |

| 事件样本 | 多次脱敏样本，能看出 ID/时间/重传/重复行为 | 单条样本、无法复现 |

| 重复/重传观察 | 设备自身产生的重复/重传记录 | 人工重放攻击 |
| 时间窗 | 厂商值或设备明确配置 | 用 Mock 5 分钟外推 |

**结论处理：**

- 有签名/nonce/时间窗/防重放证据 → 仍只能写 `confirmed`（限于该设备/固件/事件类型），G3 另审。
- 无签名/nonce/时间窗/防重放证据 → `unsupported` 或 `unknown`，**S08**；事件只作审计，不影响业务状态。
- 证据冲突 → `unknown`，不选边、不上线。

## 7. 证据规范与空白模板

> 对应 06A 全部 Q 的证据格式要求；模板见 [HK-AI-06B 设备证据模板](./HK-AI-06B-DEVICE-EVIDENCE-TEMPLATE.json)。

### 7.1 每条证据的必填字段

| 字段 | 含义 | 脱敏/占位 |
|---|---|---|
| `evidenceId` | 证据编号 `EV-*` | 内部编号 |
| `sourceType` | 来源类型：铭牌/包装/Web 页面/capability 页面/只读 API/网络设备/抓包/照片/日志/厂商书面/操作记录 | 枚举 |
| `sourceRef` | 来源引用（文档编号/页面/端点/照片 ID） | 可脱敏 |
| `collectedAt` | 采集时间，ISO 8601 含时区 | 必须 |
| `operatorRef` | 操作人占位 | `<OPERATOR-REF>` |
| `deviceRef` | 设备内部引用 | `<DEVICE-REF>`，不用序列号 |
| `firmware` | 版本 + build + 区域 | 版本可公开 |
| `endpoint` | 候选端点/页面 | 候选标记 |
| `requestSummary` | 方法、路径、关键字段（脱敏），≤500 字符 | 不含原始敏感值 |
| `responseSummary` | 状态码、关键字段/错误码（脱敏），≤1000 字符 | 不含原始全文 |
| `redactionRuleId` | 使用的脱敏规则 `R-*` | 必须 |
| `conclusion` | `confirmed` / `unsupported` / `unknown` | 枚举 |
| `rollbackResult` | `pass` / `fail` / `not_applicable` / `not_started` | 必须 |
| `attachments` | 脱敏附件 ID/哈希 | 不含原图 |
| `sha256` | 证据文件哈希 | 必须 |
| `reviewerRef` | 复核人占位 | `<REVIEWER-REF>` |

**所有字段均可脱敏或置空；禁止在证据中填入原始 IP/MAC/序列号/账号/密码/Token/人脸。** 如果某字段无法脱敏，则不采集该字段，而不是“先记下来再说”。

### 7.2 结论与回滚结果

| 结论 | 使用条件 | 禁止 |
|---|---|---|
| `confirmed` | 直接观察 + 可复核 + 无冲突 + 设备/固件明确 | 用公开文档/近似型号/Mock 代替 |
| `unsupported` | 设备明确不支持/字段明确缺失 | 把“没找到”写成不支持 |
| `unknown` | 默认；未执行/不可读/冲突/证据不足 | 用“应该支持”填空 |

| 回滚结果 | 含义 |
|---|---|
| `pass` | 回滚完成，回读证明无残留 |
| `fail` | 回滚失败/无法证明；设备隔离 |
| `not_applicable` | 该证据不涉及写操作 |
| `not_started` | 尚未回滚；不得结项 |

### 7.3 脱敏规则

| 规则 ID | 对象 | 方法 | 允许输出 |
|---|---|---|---|
| `R-ID-01` | MAC/序列号/二维码 | 默认删除；仅末 2 位或 `<MASKED-*>` | 掩码值 |
| `R-ID-02` | IP/网关/DNS/端口 | 用 `<TEST-PC-IP>` 等占位符替换 | 占位符 |
| `R-ID-03` | 账号/密码/Token/Cookie/密钥 | 删除；不记录哈希 | 无 |
| `R-ID-04` | 人脸/指纹/生物特征 | 删除/不采集；只留“合成图”类别与哈希 | 无原图 |
| `R-ID-05` | 原始配置 | 只留字段清单/差异摘要 | 摘要 |
| `R-ID-06` | 截图 | 裁剪/遮挡/去 EXIF/关通知 | 脱敏图 |
| `R-ID-07` | pcap | 过滤/截断/加密；认证头删除 | 脱敏 pcap 或哈希 |
| `R-ID-08` | 日志 | 删除 PII/标识/URL 查询参数 | 摘要 |
| `R-ID-09` | 厂商文档 | 删除序列号/联系人/价格 | 摘录 |
| `R-ID-10` | 自由文本 | 人工复核 + 敏感扫描 | 复核后文本 |

**默认规则：** 脱敏优先、最小化、不可逆；不能脱敏就不采集/不提交。所有证据包提交前必须跑敏感扫描并零命中。

### 7.4 证据链、留存与销毁

| 项目 | 规则 |
|---|---|
| 哈希 | 每个文件 SHA-256；证据包清单含文件名/大小/哈希/分类 |
| 存储 | 加密离线介质；双人保管；访问登记 |
| 仓库 | 只存脱敏摘要/清单/哈希；不存原始配置、pcap、人脸、凭据 |
| 留存 | pcap 建议复审后 30 天；证据包建议 180 天；测试人脸 ≤24 小时；最终由安全/隐私批准 |
| 销毁 | 到期安全删除/消磁；记录销毁人/时间/方法/见证人 |
| 传输 | 只传脱敏证据包；不传原始文件；不使用个人云盘/聊天工具 |

## 8. 停止条件与处置

> 任一条件触发即停止；停止不需要审批。先保证人身/设备/数据安全，再记录证据。

| ID | 停止条件 | 检测方式 | 立即动作 | 恢复条件 |
|---|---|---|---|---|
| S01 | 型号或固件不符 | 铭牌/包装/系统信息/`deviceInfo`/审批单任一不一致；后缀不清 | 不写、不上电（若未上电）；记录脱敏证据；通知项目/厂商 | 厂商/项目书面确认 + 新基线 + Codex 复审 |
| S02 | 电压/电流/极性不确定 | 铭牌缺失/磨损；适配器不匹配；万用表读数异常 | 断电、拔插头、LOTO；不上电 | 电气负责人书面确认 + 合规适配器/铭牌证据 |
| S03 | 生产网 | 上联/生产 VLAN/默认路由/生产 DHCP/DNS/生产设备/云连接 | 立即断开；不抓生产流量；按安全事件上报 | 网络负责人书面隔离证明 + 新拓扑 + 重新审批 |
| S04 | 真实人员或真实人脸 | 出现员工/访客/真人照片/视频帧/证件照/生物特征 | 停止；不上传、不存储；隔离；按隐私事件处理 | 隐私负责人批准 + 仅合成数据 + 重新审批 |
| S05 | 需要真实管理员凭据 | 只允许生产管理员/共享账号/默认密码登录 | 不登录、不猜密码、不借用账号 | 专用实验室设备 + 最小权限专用账号 + 书面批准 |
| S06 | capability 冲突 | Web/API/06A 文档/实测互相矛盾；`supportFunction` 不一致 | 停止写；标 `unknown`；保留证据；不“试一下” | 厂商书面答复 + 重新复审 |
| S07 | 删除或权限语义不清 | 删除不级联/进度不明/权限模板不明/特殊模板 | 停止后续写；测试对象隔离；不接生产 | 厂商/契约澄清 + 单独审批 |
| S08 | 事件无签名或无防重放证据 | W6/W7 后无签名/nonce/时间窗/重传/稳定 ID 证据 | 事件只作审计；不改变业务状态；通知安全 | 厂商证据 + G3 独立安全复审；或接受仅审计 |
| S09 | 设备异常重启/过热 | 非预期重启/卡死/异味/变色/异常烫手/告警 | 急停/断电、拔插头、隔离；不重启、不升级、不复位 | 厂商诊断 + 硬件检查 + 新审批 |
| S10 | 脱敏失败/敏感泄露 | 完整 IP/MAC/SN/账号/密码/人脸出现在文件/日志/截图/pcap | 停止；隔离/删除不安全副本；按事件上报；重新脱敏 | 安全复核 + 扫描零命中 + 重新审批 |
| S11 | 未审批/并行/超范围 | 无审批/过期/设备或固件不符/并行测试/超范围 | 立即停止；撤销审批；断开 | 新审批 + 重新基线 |
| S12 | 时间偏差超阈值 | `abs(offset) > 5 s`（内部预检值）或 NTP 未同步 | 停止事件/写测试；校时；记录 | NTP 稳定 + 偏差达标 + 重新基线 |

### 8.1 停止后的通用处置

1. 先急停/断电/断网（按风险），再记录；不先“排查一下”。
2. 保留脱敏证据：时间、设备引用、固件、触发条件、已执行步骤、截图/日志哈希。
3. 不删除原始证据（除非含未脱敏敏感值；此时按 S10 隔离并记录）。
4. 通知项目负责人、见证人、对应安全/电气/隐私角色；设备贴“隔离封存”。
5. 未完成根因分析、未重新基线、未重新审批，不得恢复。
6. 任何停止都写入证据包；复审时说明“为什么停、停了多久、如何恢复”。
