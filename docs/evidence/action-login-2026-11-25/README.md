## 本轮规则

公开房源、社区内容、搜索筛选、详情、图片、VR、分享和关于可以匿名浏览。电话咨询、在线咨询、关注、收藏、预约草稿、个人服务、物业、家庭、门禁、消息、测试入住及人脸操作需要当前登录态。小程序登录入口和申请开通码自身不套登录门，避免循环。

未登录时统一弹出“请先登录”，可选“去登录／暂不登录”；确认只前往“我的”，在那里保留手机号和账号密码两种登录方式。不自动拨号、预约、发送或上传，登录后由用户重新发起原操作。并发操作共用一个提示。

共用`utils/require-login.js`采用显式API依赖；缺getProfile、身份异常或查询失败均不视为已登录。live要求明确authenticated:true和合法用户ID。demo仅识别已有的明确演示资料，不将其当作真实身份，也不放开演示模式原有的云／设备禁用。

私有API在调用云函数／上传前检查当前资料；异步云返回及上传回执会复核登录代次。退登期间已经提交的网络请求无法收回，但不接收其旧回执或继续下一步业务。私密页面重新进入和退出后清理旧视图，并通过页面请求版本／身份复核阻止迟到数据回填。公开页匿名时忽略旧关注／收藏缓存，不因此弹窗；本轮不宣称已实现全设备缓存的多账号隔离。

这些是客户端操作与展示约束，不能替代云端可信APPID/OPENID、住户房产权限、审批及设备授权。原入住审核、固定租期、照片用途确认、唯一房号102和设备总开关保持；栖山苑242间及首层隐藏规则保持。

## 密码规则覆盖

用户明确将最低长度从12改为8。本轮服务端权威校验、后台开通／重置、客户端校验及提示统一为8–128个JavaScript字符单位，UTF-8最多256字节；原文、盐化scrypt、持久限速、同微信绑定、CAS及无明文持久化要求不变。既有12位密码继续有效，7位拒绝，8位接受。

负责人指定的账号仅用于测试；其真实账号和密码不写入源码、清单、日志或公共ZIP。当前负责人确认账号入口尚未部署，因此状态为`NOT_CREATED_DEPLOYMENT_PENDING`，不能声称已开户或已经能够登录。

## 实际开通的前置与操作

1. 由获授权本地执行方按包内`cloudfunctions/accountLogin/README.md`，在独立测试云部署账号服务及同版身份模块，核验五个私有集合拒绝客户端直接读写、users敏感字段仅服务端维护。
2. 测试用户从小程序账号密码页生成本人短期开通码；该码有效10分钟，不接受手机号自行代替微信身份，不接受客户端指定另一userId/openid。
3. 管理员在受保护后台“租客账号密码”输入有效开通码及负责人本地提供的账号／至少8位初始密码完成开通。不要把真实密码放入Git、shell命令历史、截图或公开任务卡。
4. 同一微信下验证账号密码及手机号均落在同一用户；房屋权限不由登录页面授予。确认退出后再点击电话／咨询／收藏／入住均先提示登录。

本轮没有部署云函数或权限、没有创建／重置真实账号、没有访问真实微信、支付或设备。包是源码ZIP，尚非平台体验版；测试通过不能冒充上传、线上账户开通或现场人脸通过。旧包和历史验收工件保留，不重开EOF/旧P2或合同政策。
