# 第一版演示倒排计划（2026-11-15）

制定日期：2026-11-05  
演示日期：2026-11-15  
演示类型：M1 模拟闭环  
演示环境：本地/隔离测试环境、Mock Provider、脱敏固定数据

## 1. 演示目标

用一个稳定、可重复的流程展示：管理员登记模拟门禁设备，提交并审核住户人脸资料，创建门禁授权任务，查看 Mock 执行结果，处理失败/未知状态，最后撤销授权并查看审计记录。

本次演示验证产品流程和软件边界，不证明 `DS-K1T671BM` 已完成真实接入。真实 capability、真实 Provider、设备录入、现场开门和生产灰度属于 M2。

## 2. 必须交付的演示范围

### 后端

1. 使用已经复审的 DB-02～DB-07 集成能力和 `face-biometric` 私密文件策略。
2. 完成厂商无关设备、凭证、授权、任务、日志服务。
3. Mock Provider 固定支持：成功、设备离线、发送前失败、发送后未知、终态失败和撤权失败。
4. 权限、组织隔离、幂等、任务租约、退租立即失效、未知结果禁止自动重复写入。
5. Demo/test 可选择 Mock；live 模式选择 Mock 必须失败关闭。

### 电脑端管理后台

1. 模拟设备登记和状态查看。
2. 人脸申请列表、详情、批准、拒绝、撤销和补件。
3. 人脸原图按独立权限查看，不在列表或普通详情泄露。
4. 授权对象、房间、有效期和模拟设备选择。
5. 任务状态、失败原因、未知结果提示和允许范围内的人工处理。
6. 操作审计查询；页面持续显示“Mock 演示，未连接真实门禁”。

### 演示数据与脚本

1. 固定一个组织、一个小区、一栋楼、两层、六个房间。
2. 固定三类人员：正常主租客、待审核成员、限制名单复核人员。
3. 固定两台模拟设备和六类 Mock 结果。
4. 提供一键重置或可重复导入的脱敏演示数据。
5. 提供 10～15 分钟演示脚本及异常时的备用路径。

## 3. 本次明确延期

## 6. 质量门禁

演示候选包必须同时满足：

1. 演示数据不含真实身份证、人脸、手机号、设备地址或凭据。
2. Mock 标识在设备、申请详情和任务结果页面持续可见。
3. 无私密读取权限时，列表、详情、下载和旧公开路径均不能取得人脸文件。
4. 发送后未知状态不能直接再次新增；撤权失败不能恢复业务授权。
5. 跨组织和猜测 ID 返回同态拒绝。
6. 演示数据可在 5 分钟内重置，连续两次完整彩排成功。
7. 发布包、提交号、测试结果、已知限制和回退包均有记录。
