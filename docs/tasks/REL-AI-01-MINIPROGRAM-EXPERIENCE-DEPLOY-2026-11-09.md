**负责人：Workburry（发布 AI）**

**优先级：P0**

**发布对象：** 微信小程序体验版，不是正式公开发布

**唯一允许基线：**

- 分支：`release/miniprogram-production-test-beta18`
- 提交：`6e18d04ad958f00a602b92cdfdf2a36297c25230`
- 标签：`v0.1.0-beta.18-production-test.1`
- AppID：只核对仓库既有配置，不在回报中重复完整值
- 云环境：只核对仓库既有配置，不在截图或普通日志中暴露完整标识

## 1. 上线目标

将已经冻结的 beta.18 production-test 包编译并上传为微信**体验版**，供授权测试账号验证真实登录、内容、房源、消息与个人中心。真实门锁操作保持关闭。

本任务不包含当前开发中的 H2-c、人脸管理后台或任何未合并功能。不得从 feature/docs 分支拼装“最新版本”。

## 2. 本地预检

必须在独立、干净工作区完成：

1. checkout 精确标签并核对 `HEAD=6e18d04`；
2. `git status --porcelain` 必须为空；
3. 核对 `package.json` 和 `miniprogram/config/version.json` 均为 `0.1.0-beta.18-production-test.1`；
4. 核对 runtime 为 `mode=live`、`allowDeviceOperations=false`；
5. 运行：
   - `npm test`；
   - `npm run check`；
   - `npm run verify:backend`；
   - `npm run release:live`；
6. 解压生成包，在独立目录再次运行发布脚本要求的检查；
7. 记录 ZIP 文件名、字节数和 SHA-256，不提交 ZIP、凭据或登录信息到 Git。

任一检查失败即停止，不修改标签、不就地修复发布包；另开修复分支并回报阻断。

## 3. 微信开发者工具预检

使用已有授权登录会话，不在聊天、仓库、命令行或截图中记录二维码、cookie、token、openid、手机号或云凭据。

1. 导入本次生成并校验过的解压目录；
2. 核对项目 AppID 与目标小程序一致；
3. 核对选择的是既有目标云环境；
4. 核对当前平台已上传/体验版本并记录脱敏版本号和时间，作为回退依据；
5. 编译并确认无 WXML、JS、依赖、云环境初始化错误；
6. Network/控制台不得出现未知域名、凭据或真实设备写请求；
7. 不执行 `dbInit/contentInit/chatInit/syncDevices`，不初始化、迁移或覆盖云数据库。

## 4. 云函数边界

- 先只读核对 `contentList/getHouses/phoneLogin/messageList/messageRead/messageSend/getDevices/unlockRecords` 是否存在；
- 禁止整批覆盖云函数；
- 若必要函数缺失或远端版本无法确认，停止上传并记录函数名与脱敏错误，不用旧本地副本猜测覆盖；
- `getHouses` 如需更新以保证公共用房过滤，必须先导出/记录当前远端版本及回退点，只部署仓库该标签对应函数，并选择“云端安装依赖”；
- 不部署任何人脸、海康、门禁写或数据库初始化函数。

## 5. 上传体验版

本任务授权上传为体验版，版本号固定为 `0.1.0-beta.18-production-test.1`。上传说明应写明：

```text
生产环境受控测试版；真实设备操作关闭；不含未完成的人脸门禁集成。
```

上传后记录：

- 上传结果；
- 平台显示的版本号与上传时间；
- 执行人；
- 构建 ZIP SHA-256；
- 微信开发者工具版本；
- 是否改动云函数，若有则记录函数名、前后版本与回退点。

不得提交审核、发布正式版或扩大体验成员范围。

## 6. 体验版冒烟测试

仅使用授权测试账号和脱敏测试数据：

1. 启动、首页和导航；
2. 手机号授权取消路径、成功路径及退出；
3. 内容与房源列表、详情、空态；
4. 消息列表、读取和明确测试会话内的发送；
5. 我的页面；
6. 开门页只能读取允许设备与自己的记录；
7. 点击开门不得发出设备命令，页面应显示关闭或拒绝；
8. 云失败不得回退为演示成功。

记录每项通过/失败和脱敏错误码。不得使用真实住户资料、真实人脸或生产门锁进行测试。

## 7. 停止与回滚

出现以下任一情况立即停止：

- 版本、提交、AppID、云环境不一致；
- `allowDeviceOperations` 不是 false；
- 编译或预检失败；
- 需要数据库初始化/迁移；
- 出现未知云函数、未知域名或真实设备写请求；
- 登录、组织隔离、公共用房过滤或消息权限异常；
- 平台要求覆盖无法确认来源的远端云函数。

体验版异常时撤回本次体验入口或重新指定此前记录的体验版本；云函数若发生更新，按预先记录的远端回退点恢复。不得通过打开设备写开关、切 demo 或修改线上数据掩盖失败。
