# 手机号登录测试（v0.1.0-beta.8）

本地已完成 46 项测试，其中新增 10 项登录测试。云函数测试替换了微信 SDK 和数据库，不会创建真实账号；不能代替微信真机授权。

## 开发者工具操作

1. 导入 beta.8 项目根目录（包含 project.config.json）。确认 AppID 为 `wxd83b20cbba2a0b24`。
2. 检查 `miniprogram/config/runtime.js`：`mode: 'live'`、`cloudEnv: 'cloud1-d6gs08jbb8aa7a138'`。演示模式不提供真实登录。
3. 在云开发控制台选中上述环境。此次仅 phoneLogin 代码有变动；如线上有另行修改，先比较保留。在工具中右键 `cloudfunctions/phoneLogin`，选择“上传并部署：云端安装依赖”。确认部署完成。不要运行 dbInit 或重置现有数据库。
4. 点击“编译”，进入“我的”，点击“手机号快捷登录”。先取消授权：应保持未登录，按钮恢复可用。
5. 使用“预览”扫码，在微信中重新点击登录并同意手机号授权：应显示用户资料，登录按钮消失。检查云端 users 中对应当前微信身份的账号是否保存手机号；重复登录应更新原账号。
6. 若 owners 已有匹配手机号及 houseId，检查 users.houses 是否同步。没有房产记录的新用户应登录成功、保持无房产。
7. 在“我的 → 设置”退出账号：应恢复登录按钮。当前登录资料仅缓存在内存，重新启动小程序后需要重新授权登录。

若登录失败，查看 phoneLogin 云函数日志及页面提示，排查部署、环境关联、手机号能力权限/额度和 users 集合。分享错误时请隐去手机号、OPENID、授权 code 等个人信息。

此次没有上传微信平台、调用真实手机号接口、初始化数据库或开启真实门锁操作。
