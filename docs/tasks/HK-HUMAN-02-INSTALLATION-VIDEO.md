# HK-HUMAN-02 海康门禁手动安装视频任务卡

- 负责人：Kimi（脚本、分镜、字幕、剪辑方案与资料整理）
- 真人负责人：项目现场人员（断电施工、端子核验、接线、测试与拍摄）
- 设备：海康 DS-K1T671BM、PDC-K7B-12V5A 门禁电源
- 优先级：P1
- 目标：制作一份可供安装人员照着执行的中文视频，不包含真实密码、IP、证书指纹、住户信息或人脸样本

## 交付物

1. `docs/install/HIKVISION-INSTALL-VIDEO-SCRIPT.md`：完整旁白、画面、字幕和安全提示。
2. `docs/install/HIKVISION-INSTALL-SHOT-LIST.md`：现场逐镜头拍摄清单。
3. `docs/install/HIKVISION-INSTALL-WIRING-CHECKLIST.md`：接线与通电验收表。
4. 一份6–10分钟横屏成片方案；如获得真人拍摄素材，再输出1080p MP4成片与60秒故障排查短版。
5. 成片素材清单和版本记录；大视频不直接提交 Git，仓库只保存说明、校验值和受控存储位置。

## 视频章节

1. 设备确认：展示完整型号、门禁机背部接口、PDC-K7B 铭牌和门锁铭牌。
2. 工具准备：万用表、绝缘螺丝刀、剥线/压线钳、冷压端子、网线测试仪、保险保护、标签与绝缘材料。
3. 断电与测量：确认220V断开，万用表确认无电；识别12V正负极。
4. 设备供电：按端子丝印连接门禁机红黑供电，不根据线色以外的信息猜端子。
5. 门锁控制：解释 COM/NO/NC、断电开门与通电开门；门禁机使用无源继电器控制门禁电源。
6. 出门按钮与门磁：PUSH/GND、DOOR/SENSOR/GND 的接法与配置。
7. 分阶段通电：先不接锁测试12V，再测继电器，最后接锁。
8. 验收：人脸/卡片、出门按钮、门磁、断网、断电、恢复供电及开门延时。
9. 常见错误：正负极反接、把12V灌入干接点、NO/NC选错、锁电流过大、线号缺失和网络未隔离。

## Kimi 执行要求

1. 先阅读仓库中的 LOCK-01/HK-AI 文档，但不得把软件接口推断成物理端子定义。
2. 接线名称只引用设备外壳丝印、随设备说明书或真人万用表确认结果；看不清的端子标记为“待真人确认”。
3. 每个接线镜头同时显示：端子名、线号、输入/输出类型、电压和断电状态。
4. 旁白明确：`COM/NO/NC` 通常为无源继电器触点，本身不等于12V输出。
5. 220V施工必须由具备相应能力的真人完成；视频不得演示带电剥线、短接或插拔端子。
6. 不展示设备密码、内网地址、序列号、MAC、完整证书指纹及真实人脸。
7. Kimi 不直接决定现场 NO/NC；必须由门锁铭牌的“断电开门/通电开门”属性决定。

## 真人需提供的素材

- 门禁机完整型号和背面端子近照；
- PDC-K7B 绿色端子排正面清晰近照；
- 门锁型号、12V电流及断电状态铭牌；
- 断电确认、压接端子、万用表测量和线号镜头；
- 首次通电及六项验收的连续镜头；
- 拍摄人确认画面中没有凭据和个人信息。

## 验收标准

- 端子顺序与现场丝印逐项一致，至少两人复核；
- 无“按线色盲接”、无带电施工、无门锁直接超载门禁机输出；
- 接线图、字幕和实物镜头一致；
- 展示先测电、再控制、最后接锁的顺序；
- 覆盖断电开门/通电开门差异及消防要求提示；
- 视频中所有敏感信息已遮挡，仓库无原始敏感素材；
- 未获得清晰端子证据前只能交脚本/分镜，不得生成声称可直接施工的最终成片。
