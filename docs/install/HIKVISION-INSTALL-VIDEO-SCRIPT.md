- 状态：**仅供 Codex 与现场人员复审，不可直接用于施工，尚未生成 MP4**

## 1. 使用边界

1. 本稿依据 [HK-HUMAN-02 任务卡](../tasks/HK-HUMAN-02-INSTALLATION-VIDEO.md)编制。LOCK-01/HK-AI 文档只用于软件与隐私边界，不作为物理端子证据。
2. 门禁机登记型号为 `DS-K1T671BM`，电源登记型号为 `PDC-K7B-12V5A`；完整后缀、背部丝印、绿色端子排和门锁铭牌仍须真人清晰拍摄并双人核对。
3. 所有“待真人确认”必须保留到证据齐全。不得把画外音、字幕或示意图补成未确认的端子号、NO/NC 选择、锁电流或电压读数。
4. 220 V 作业由具备相应能力的真人按现场安全规程完成。视频不演示带电剥线、短接、插拔端子或以试电方式猜端子。
5. 接线镜头须同屏显示：端子名、线号、输入/输出类型、电压、断电状态。线色只作辅助，丝印与测量才是核对依据。
6. 人脸/卡片验收使用获授权的测试身份；画面只拍测试结果，不展示真实人脸、住户信息、密码、内网地址、序列号、MAC、二维码或完整证书指纹。
7. 消防、紧急疏散和当地电气要求优先。现场未确认这些要求前，不得将视频或设备标记为“可供安装使用”。
