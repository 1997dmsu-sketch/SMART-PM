# 只读宿主受控CLI：离线接入

本阶段基于 `c3f8176d33f43e14aa498aa52679e29865ac0674` 新增独立只读入口，保持原登记命令、SDK、宿主、策略、后台和worker不变。宿主范围见[说明](ADMIN-FACE-READONLY-HOST.md)。

## 实际可执行入口保持锁定

```text
node admin-web/face-readonly.mjs --help
node admin-web/face-readonly.mjs
```

`--help`只输出帮助，不读取stdin、文件、环境连接材料或建立传输。其他调用按严格输入协议检查后，默认执行路径仍返回非零和固定的实机执行锁定类别；不存在可从argv、环境变量或JSON打开的运行开关。不是通过输入 `mode=device` 就能访问设备。

离线完整链路由 `admin-web/tests/fixtures/` 内的专用子进程装配：先安装拒绝真实网络的守卫和合成TLS/HTTPS底层，再调用同一个CLI主函数及固定宿主适配层。品牌化runner仅为代码级测试依赖，不能由输入提供函数、模块路径、provider或通用请求。生产入口不导入测试fixture，不传测试runner。

这是一项离线接入交付，不能作为现场可运行CLI、真实TLS或设备兼容性验收。代码级测试能力也不是针对任意可信JavaScript代码的安全沙盒。

## 输入及输出范围

输入为原始UTF-8字节流中的单个JSON对象，最多32768字节，且必须在有限期限内结束；非法UTF-8（含EOF截断）、重复键（含转义等价键）、多对象、未知字段/动作或过深输入拒绝。凭据和合成证书仅在内存输入中传递，不放进argv、配置文件、日志或历史命令。

合成接入只接受 `operation=list`、`mode=offline` 及严格的config/options白名单；config内的SDK设备模式只是供假底传输下的真实SDK执行，不代表实际入口可以联网。本阶段只接收内存 `certificateBase64`，不接收证书路径、照片路径、输出目录或其他文件输入；不读取真实连接配置、照片或证书文件。

输出使用独立的只读JSON协议。仅返回必要的名单、入库状态、计划和只读状态投影；`deleteAllowed=false`。输入的origin、账号密码、证书及其路径、授权头、照片/人脸模板（modelData）和原始错误/堆栈不得输出。离线成功必须明确标为合成完成，现场结果为 `NOT_EXECUTED`，不能沿用登记成功或设备验收通过的结论。

stdout仅一条协议JSON；stderr仅固定错误类别。必须以真实进程退出码和完整协议共同判断，不能只看到某个早先成功字段便认定完成。CLI观察到的输入、输出、取消或清理异常均非零，不自动重跑；不扩大为对继承宿主内部全部关闭错误的可观测性保证。

若成功行已交给输出流后才发生取消或异步写入错误，已提交字节无法撤回，最终仍须非零；消费者必须拒绝把该行单独当成成功。拒绝真实网络的测试守卫覆盖本次用例触达的Node入口，不能据此宣称任意原生代码或其他进程也被隔离。

| 退出码 | 本入口含义 |
| --- | --- |
| 0 | help，或测试夹具中的合成只读完成；查看outcome区别 |
| 2 | 输入/协议字段预检拒绝 |
| 4 | 已知设备/策略拒绝，例如pin不符；仍仅为合成验证 |
| 5 | 实机锁定、未知/传输/超时/取消/输出异常等停止结果 |

## 宿主约束继续生效

固定调用真实 `FaceReadonlyHost`，保留真实SDK的证书解析、SPKI pin-before-send与Digest，以及真实策略的精确白名单。一次connect、一次完整list，最终关闭；查询完成时宿主会主动释放连接，不能仅凭最终 `connected=false` 误判查询失败。

总时限不超过120000ms、单请求不超过5000ms、逻辑请求不超过256，只能缩短。逻辑请求与HTTP/TLS次数分开；既有同端点Digest认证往返仍最多一次。禁止所有写方法/写POST、未知请求、重定向和自动业务重试。

首错熔断持续压过后续状态，取消、超时及晚响应不得恢复成功或补发请求。仅可清零可变缓冲、释放引用，不宣称JavaScript字符串已被可靠擦除。

本阶段没有新增PowerShell包装器，也不调用旧登记包装器；旧包装器的48秒期限不代表新宿主的120秒默认期限。未来包装器接入必须单独协调期限、输出协议和清理余量。
