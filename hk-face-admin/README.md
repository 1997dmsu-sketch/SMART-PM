# HK 人脸门禁管理后台 · 合成数据演示 UI

分支：`feat/hk-face-admin`（SMART-PM 仓库 worktree，基线 `708c3ab`）
本轮交付：HK-AI-05A《门禁管理页面演示门禁修复》

## 一、本轮定位

把原有「零依赖静态页面壳」改造为**合成数据演示 UI**，用于第一版演示。核心是明确区分
Mock 证据与真实设备证据，补齐关键页面状态、权限分流与未知结果对账表达。

**仍然不接 HTTP 接口、不调用 Provider、不连接真实门禁、不实现后端权限。**
页面上的所有操作只改变本地合成 fixture 或显示说明，不产生任何业务写入。

## 二、文件清单

| 文件 | 说明 |
| --- | --- |
| `index.html` | 概览 / 导航中枢，列出四个模块与本轮边界 |
| `devices.html` | 设备管理：合成设备台账与 Provider 边界 |
| `applications.html` | 申请管理：合成申请详情、理由必填的本地审批演示、权限分离 |
| `tasks.html` | 任务中心：合成任务、未知结果人工对账、受控重试门控 |
| `audits.html` | 审计日志：合成六类事件（带理由与结果） |
| `styles.css` | 共享样式：Mock 横幅、六态面板、显式焦点、响应式与打印 |
| `app.js` | 共享脚本：合成 fixture、六态驱动、toast、本地演示交互 |

## 三、如何打开

直接用浏览器打开 `index.html`（`file://` 双击可用），无需依赖、无需服务、无需联网。

- 零第三方依赖、零框架、零外链；仅引用同目录的 `styles.css` 与 `app.js`；
- 五页互链，侧边栏与面包屑「概览」均可点击返回；
- 打印时隐藏侧栏、操作按钮与状态切换控件，**Mock 横幅在打印态保留**。

## 四、全局 Mock 状态边界

五页首屏均持续显示统一横幅（颜色 + 文字同时表达状态，不依赖单一颜色）：

> **Mock 演示，未连接真实门禁**

只读状态：`executionMode=test`、`provider=mock`、`evidenceScope=simulated`、
`真实设备生效：否`。横幅在切页后仍存在，打印态不隐藏（打印会保留底色）。
页面不提供切换到 `live` 的入口，也不使用任何声称设备已真实同步或授权已真实生效的误导表述。

## 五、六类页面状态

四个业务页各有一个状态切换控件，**仅切换合成 UI 状态**，六态为：
`loading` / `empty` / `forbidden` / `error` / `retrying` / `ready`。

- 每个状态有肉眼可辨的面板差异：骨架屏、虚线空框、无权限锁屏、脱敏错误分类、
  受控重试进度、就绪态数据表；
- `forbidden` 态分别对应缺少 `device.face.read` / `device.face.review` /
  `device.operation.retry` / `device.audit.read`；
- 默认态为 `ready`；**刷新强制恢复默认**，不读取浏览器本地存储，不发任何网络请求；
- 状态切换只重渲染本地容器，不改动其它页面或持久数据。

## 六、各页演示要点

- **设备页**：合成记录带脱敏编号（`DEV-DEMO-*`）、型号、固件（`FW-DEMO-*`）、
  capability 状态、灰度状态、Provider 边界、在线状态与最近心跳；均为虚构值。
  新增 / 同步 / 导出按钮均为「演示占位」，无副作用。
- **申请页**：合成申请详情含人员代号、房间代号、入住周期、目标设备、授权起止时间、
  审核状态、同意记录。审核 / 拒绝 / 撤销 / 补件**操作前必须填写理由**，空理由不执行并提示；
  审核权限不自动获得私密读取权限，两者为独立开关；私密内容区域只显示「需逐次授权查看」
  占位，不加载任何图片、外链或字节，不实现真实文件读取或下载。
- **任务页**：合成 `jobId`、`action/state`、`attempts`、`failureReason`（脱敏合成文本）、
  `lastSuccessAt`、Provider 边界。包含 `awaiting_result / UNKNOWN_RESULT` 示例，该行**只允许
  查询 / 人工对账**，不提供重复下发，系统自动重试已关闭；受控重试按钮**只在 retryable 状态**
  展示，并受 `device.operation.retry` 开关门控，缺权限时按钮禁用并说明原因。
- **审计页**：合成批准 / 拒绝 / 查看原图申请 / 重试 / 撤销 / 人工对账事件，带理由与结果。
  已移除两个未冻结的展示位，列表仅保留已冻结字段；不声称日志已写入真实不可变存储。
  「查看原图申请」仅为合成事件类型名，不含任何图片或外链内容。

## 七、可访问性与反馈

- 所有可交互控件有显式 `:focus-visible` 焦点环，不依赖浏览器 UA 默认焦点环；
- 表格横向滚动容器显式带 `tabindex="0"`、焦点样式与无障碍标签；
- toast 使用 `role="status"` / `aria-live="polite"`，带关闭按钮，可按 `Escape` 关闭，
  驻留至手动关闭（不再短时自动消失）；审核理由错误用 `role="alert"` 提示；
- 次级文字与 Mock 壳标识对比度已提升到 WCAG AA 普通文本阈值以上。

## 八、明确边界（重要）

1. 未接入任何真实接口、真实数据、真实门禁设备或 Provider；统计值均为合成演示值，
   不代表真实指标。
2. **网络请求 0、真实设备 / Provider 调用 0**：不新增任何网络调用、设备访问或云调用。
3. 不使用真实人员信息、真实硬件标识或任何真实私密材料；页面与表头均不含可能承载敏感值的
   展示位；合成记录一律使用 DEMO 前缀代号。
4. 不嵌入图片、编码内联内容、外链、对象存储键或内容概要，不实现真实文件读取或下载。
5. 不把 Mock / fixture 结果标为真实设备生效；不实现真实权限、登录或审计落库。
6. 未合并 `main`，未改写基线历史；不顺带实现 H2-b / H2-c / H3 / H4 或真实 Provider。
7. 静态检查与脱敏截图由独立提交交付，不与页面改动混在同一提交。
