4. 保留手机号及账号密码登录、管理员开通密码、最低8位。管理员针对已完成手机号注册的住户关联用户名／密码，不再使用开户码；不接受客户端自报手机号替代微信核验，不允许直接指定他人OPENID绑定。

这四项来自本轮用户明确消息，生效于需求范围；不修改已关闭v4或历史测试证据。现有代码与最新需求不一致的地方，明确进入[缺口清单](FUNCTION-GAPS.md)。

## 3. 阅读状态的方法

需求确认、代码实现、离线验收、分支集成、部署、用户端验收分别记录。**有页面不等于有业务；有API不等于页面已接入；本机草稿不等于提交成功；测试包不等于平台体验版；分支验收不等于已合入或上线。**

- 确认主值：已确认、已提出待确认、建议、暂缓/取消/被替代、来源不足。待确认功能也必须登记，但不当作已批准开发范围。
- 实现主值：已实现、部分实现、未实现、未知。未实现必须限定到实际阅读的固定版本及路径；不能用一次检索无命中断言全仓／所有分支不存在。
- 验收／集成／上线：是、否、部分、未知，旁注明确对象和范围。没有现网证据就记未知；本轮明示未进行的上传、部署记本轮未执行。
- 详细文档中的“最低验收”是本次补充的产品／技术验收建议，等待相应实施卡复核，不是声称已执行或以此新增业务政策。
