# Windows 私密输入适配：仅合成离线接入

本阶段在 `d8ceda2271f7ecdc36d298d98a21144ef47477d6` 的原生证据接收器之上增加固定 Windows PowerShell 5.1 私密管道适配。输入、独立预期、审批事件、证书和设备响应全部为合成材料；网络通过假传输替换并安装出站拦截。实际 `admin-web/face-readonly.mjs` 不安装 runner，仍返回 `LIVE_EXECUTION_LOCKED`。

## 实现范围

- `face-readonly-windows-input.mjs` 只接受原始 `Uint8Array` 输入和独立预期字节，立即复制到私有状态。输入上限 32768 字节，预期上限 8192 字节。无配置路径、辅助程序路径、回调、任意输出目的地或解锁开关。
- 固定 `powershell.exe -NoLogo -NoProfile -NonInteractive -File` 启动固定 helper；不使用 `pwsh.exe` 替代，不修改执行策略。helper 只处理父进程提供的内存字节，不读取连接文件、凭据、照片或设备。
- helper 使用严格 UTF-8 和有界 JSON 行协议。输入字节经过 base64 私密管道往返，不经过文本管道重编码或 trim。Node 核对逐字节等价后，继续使用原有严格解析和私有快照。
- 独立预期与输入为两个字段；原有会话继续核对证书 pin、序列号、计划指纹、人数和目标人脸库。外部对象不能替换两者的同域配对。
- 一个适配器只允许领取一次；其输入端口与审批端口只允许配对到一个上下文，不能混用、重放或跨上下文复用。
- 审阅响应必须匹配本次 capture、随机 challenge、精确视图字节和证据引用。原生证据目的地成功打开后才能审阅；批准响应还必须等 helper 关闭 ACK、实际退出 0、无尾部输出且无已锁存错误，才能转换为原有单次审批票据。
- 未提供合成确认事件默认拒绝；reject、cancel、none、畸形响应、绑定变化、超时或异常退出均停止，不能发 HTTP。收尾等待 helper 自身的有界关闭，不由较短业务 I/O 超时提前截断。
- 保留原有入口/出站层双重阻写、精确请求白名单、pin-before-send、取消与异常熔断、原生证据 ACL、文件身份检查及候选封存规则。

## 边界

`createSyntheticWindowsConfirmation` 产生的是不可序列化的代码内品牌事件。它用于验证消息和授权生命周期，**不是 Windows 身份认证，也不是现场真人点击证明**。本阶段没有实现可输入真实账号密码的 GUI，没有读取真实用户身份，没有把普通管道响应认作独立可信审批。

私密 helper stdout 是内部 IPC，含合成输入的编码副本，不得接入公共日志。公共边界只输出原有脱敏 DTO、固定错误码与无敏感字段的检查结果；工件保留外层测试进程的 stdout/stderr 和退出码。可变缓冲区在有界关闭收尾中清零；JavaScript/.NET 不可变字符串和运行时内存副本不保证物理擦除。

helper 与父进程属于本机相同信任域。本实现不抵御同 SID、管理员、内核、受信任代码被改写或同进程任意代码执行，不声明通用 JavaScript 沙箱。已有 Promise 构造器/原型边界、原生文件阶段检查与使用之间的非原子 TOCTOU 边界、句柄释放之后的边界继续保留。

本阶段不验证真实 TLS、路由可达、设备身份、真实公开证书来源、9 人名单或目标 `F03FF8DA7299CE148` 的实际入库状态。合成 9 人和目标命中不能代替实机读取。不授予 E1/E2，不启动 worker 或派发，不删除人员、写设备或开门。
