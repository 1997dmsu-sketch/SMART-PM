# 海康门禁安装视频：剪辑与交付方案

- 版本：V0.1-PREPRO
- 对应：主片 6～10 分钟，当前脚本 8 分 30 秒；故障排查短版 60 秒
- 当前素材状态：0 条现场素材、1 条图形演示 MP4；没有现场施工成片
- 存储边界：大视频、原始素材和工程缓存应进入受控 NAS；当前演示因 NAS 未分配而仅存工作区暂存目录，GitHub 只保存文档、校验值和存储位置别名

## 1. 后期输入门禁

开始剪辑前逐项核对：

- [ ] [拍摄清单](HIKVISION-INSTALL-SHOT-LIST.md)中的 V00～V26 和六项验收素材已登记。
- [ ] 绿色端子排、门禁机背部、门锁铭牌和完整型号均有清晰证据及两人复核。
- [ ] 每个接线镜头能读取端子名、线号、I/O 类型、电压和断电状态。
- [ ] 首次通电与六项验收有连续镜头，失败结果没有被删除或伪装成成功。
- [ ] [素材清单](HIKVISION-INSTALL-MEDIA-MANIFEST.md)已记录文件大小、SHA-256、时长、分辨率和 NAS 位置别名。
- [ ] 拍摄人已完成隐私检查；疑似敏感素材已隔离，不进入剪辑工程或代理文件。
- [ ] 未取得上述证据时，只能剪辑内部预演样片，并全程标注“待现场复核／不可直接施工”。

## 2. 工程与画面规范

| 项目 | 主片与短版统一设置 |
| --- | --- |
| 画幅 | 16:9 横屏，1920×1080；不将竖屏素材拉伸，必要时用模糊背景且遮敏 |
| 帧率 | 工程目标 25 fps；保留原始测量/验收时序，不用补帧伪造动作 |
| 成片格式 | MP4，H.264 视频 + AAC 音频；实际码率按画面质量与 NAS 配额确定 |
| 音频 | 中文旁白，保留必要现场操作声；目标响度 -16～-14 LUFS，峰值不高于 -1 dBTP |
| 字幕 | 简体中文 SRT + 成片内嵌字幕；安全提示不能被字幕、平台按钮或裁切遮挡 |
| 色彩 | 仅做曝光、白平衡和可读性校正，不改变线色、仪表读数、门锁状态或指示灯含义 |
| 画面安全区 | 关键丝印、线号和读数置于中间 80% 区域；叠加信息不遮挡实物 |
| 版本水印 | 预制作稿全程右上角“待现场复核／不可直接施工”；批准后才能按流程更换 |

## 3. 主片时间线（8 分 30 秒）

| 轨道/章节 | 时间 | 剪辑动作 | 必须保留的证据 |
| --- | --- | --- | --- |
| 安全开场 | 00:00–00:20 | 静物与警告卡，不用事故画面吸引注意 | 220 V 人员边界、不可施工状态 |
| 设备确认 | 00:20–01:00 | 全景→完整型号→端子→锁铭牌 | 原始丝印顺序、完整后缀、锁电压/电流/锁型 |
| 工具准备 | 01:00–01:40 | 工具分组特写，线号示例做匹配字幕 | 工具状态、保险保护、隔离网络 |
| 断电与测量 | 01:40–02:25 | 连续断电/验电镜头，不用跳剪省略验电 | 无电确认、仪表与实测值 |
| 设备供电 | 02:25–03:15 | 端子、线号、双手与信息条同框 | 红黑线不替代丝印、双人指读复核 |
| 门锁控制 | 03:15–04:35 | 无源触点动画与锁型分屏；实物逻辑图联动 | 干接点不等于 12 V；NO/NC 不由后期决定 |
| 按钮与门磁 | 04:35–05:25 | 实物端子与开闭状态对照 | PUSH/GND、DOOR/SENSOR/GND 和实际配置 |
| 分阶段通电 | 05:25–06:35 | 三段章节卡“测电→测控制→接锁” | 锁支路先断开；通断档前无外加电压；接锁前再断电 |
| 六项验收 | 06:35–07:45 | 六项连续镜头，保留操作、结果和时间码 | 无权限拒绝、断网实际行为、消防疏散与延时 |
| 错误与收尾 | 07:45–08:30 | 六类故障卡与批准栏 | 不用错误实操；未批准不称可施工 |

剪辑总长可在 6～10 分钟内调整，但不能通过加速造成安全提示不可读。每句安全旁白结束后至少保留完整阅读停顿；字幕重新计时时不得改变操作先后。

## 4. 接线图与信息条制作

1. 当前只使用[检查表中的逻辑图](HIKVISION-INSTALL-WIRING-CHECKLIST.md)，不得把它排成绿色端子的物理顺序图。
2. 现场照片确认后，以原图为底，按“从左到右/从上到下”的真实方向标号；两个复核人签认后才能替换逻辑图。
3. 供电用蓝色信息条、无源控制用紫色信息条、警告用红色信息条；不能仅依赖颜色区分，必须同时写文字。
4. 每个接线镜头同步显示：`端子名｜线号｜输入/输出类型｜电压｜断电状态`。值未确认时显示“待真人确认”，不得用通用数值填空。
5. COM/NO/NC 动画固定出现“通常为无源继电器触点，本身不等于 12 V 输出”。NO/NC 的最终字幕只能取自双人签字记录。
6. 市电部分只显示专业人员、断电和保护边界，不制作带电接线分步动画，不演示短接、反接或超载。

## 5. 字幕与旁白

- 主片字幕源：[`HIKVISION-INSTALL-VIDEO-ZH-CN.srt`](HIKVISION-INSTALL-VIDEO-ZH-CN.srt)，共 27 段，结束于 00:08:30,000。
- 短版字幕源：[`HIKVISION-TROUBLESHOOTING-60S-ZH-CN.srt`](HIKVISION-TROUBLESHOOTING-60S-ZH-CN.srt)，共 8 段，结束于 00:01:00,000。
- SRT 当前与脚本文本一致。现场读数或审批意见改变后，同步修改脚本、SRT、图纸和检查表，不只改成片字幕。
- 每屏建议不超过两行，每行约 20 个汉字；长句按语义断开。英文端子名保持原样，不翻译或改写实物丝印。
- 实测值、姓名和签字只在取得证据后替换空白；不能用配音虚构测量结果或批准结论。
- 校对时同时听旁白、看字幕、对照实物，特别核对“常开/常闭”“断电开门/通电开门”“输入/输出”。

## 7. 六项验收与隐私剪辑规则

1. 人脸/卡片为第1项，恢复供电及开门延时为第6项；六项均有编号、开始、操作、结果。
2. 人脸测试只保留结果页和门锁动作，不出现真实人脸。无权限测试身份的拒绝结果不能剪掉。
3. 断网、断电和恢复供电不得用旁白预设结果，字幕填写实际行为与配置。
4. 断电镜头前必须确认消防疏散和人工开门预案；任何人员受困、异常开门或危险现象不得包装成成功。
5. 密码、地址、序列号、MAC、二维码、完整指纹和住户信息使用跟踪遮挡；遮挡后检查运动镜头和倒影。
6. 含敏感信息的原始素材不复制到代理目录、云端剪辑服务或 GitHub；先隔离并交项目负责人处理。
7. 不用其他门锁、其他端子排或库存视频冒充目标设备。补充动画必须标“逻辑示意”。

## 9. 交付前四遍检查

1. **安全遍：** 无带电剥线、短接、插拔、反接、超载；先测电、再控制、最后接锁；消防提示完整。
2. **证据遍：** 端子顺序、NO/NC、锁电流和实测值均有证据；图纸、字幕、旁白、实物一致。
3. **隐私遍：** 无真实人脸、住户、密码、地址、唯一标识或完整证书指纹；遮挡在全时段有效。
4. **技术遍：** 时长主片 6～10 分钟、短版 60 秒；1080p；音画同步；字幕无重叠；SHA-256 与 NAS 记录一致。

只有四遍检查、Codex 复审、现场双人复核和安装使用批准全部完成，才可标记“可供安装使用”。
