## 4. NAS 交接流程

1. 项目负责人分配真实受控目录及访问权限，在本清单只登记位置别名与受控路径；访问凭据通过另外的受控渠道交付，绝不入 Git。
2. 拍摄人先检查敏感信息，再将素材写入指定原始素材区；疑似敏感文件直接隔离，不生成公开代理或链接。
3. 接收人逐个计算 SHA-256、字节数和媒体元数据，填写上表；不能用文件名或大小代替哈希。
4. 原始素材与工作副本各保留一份受控副本，核对哈希一致后才能开始剪辑。清理原始素材必须经项目负责人批准，不由 AI 或剪辑人员自行删除。
5. 成片导出后再次登记哈希、时长、分辨率、帧率、脚本/字幕版本和 NAS 别名；回读一次确认可解码、音画同步。
6. Git 提交前检查没有 `.mp4/.mov/.avi/.mkv`、大型工程缓存、原始照片或 NAS 凭据。大文件只通过受控 NAS 交接。

哈希计算与登记示例（对真实文件执行后把输出填入清单，不把示例当实测）：

```bash
sha256sum -- "受控文件名"
```
