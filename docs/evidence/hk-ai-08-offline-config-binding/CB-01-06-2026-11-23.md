## 2. 实现与静态核对

桥只导出 `createSyntheticBindingBridge(context)`，私有状态由每实例独立 WeakMap 持有。配置、context、假执行器预期、grant 均作闭式 own-data-descriptor 校验和防御性复制；Proxy 在反射前拒绝，拒绝 getter、隐藏/符号/未知字段、非普通原型和稀疏数组。输入和异常均不串行化输出。

`prepare` 先将安全复制的原值投影给旧 checker，再规范化并复核冻结投影，最后保存深冻结私有快照。这样不以大小写或 trim 规范化掩盖原始非 ASCII 主机、显式端口或型号问题。执行视图只从同一快照生成，额外的 TLS/材料、限制、输出引用、版本、合成凭据及六端点由桥另行校验，不能借 checker PASS 补齐。

私有 CA 为冻结普通字节数组；内建假传输得到独立 Uint8Array 副本，修改副本后核对私有字节未变。没有公开快照/材料读取 API，也不依赖 freeze Buffer。所有公开句柄均为无字段、null 原型、冻结对象，品牌来自私有 WeakMap；随机 `configBindingRef` 只作非敏感关联，不作为内容摘要、对象身份或授权证明。

合成许可与配置句柄独立，每绑定最多签发一次，绑定批准引用、快照身份、context epoch 和单调合成时间窗。消费在任何 await/假执行前同步完成，微任务边界后重查撤销、到期及 epoch；失败、抛出或不匹配不恢复许可。公开的合成签发器不是可信审批机构，不能验证真实批准单；窗口也不是已落实的真实时钟/撤销服务。

原输入 `allowRead=true` 被拒绝；桥不把它改成 false 放过。执行视图始终 `allowRead=false`，有效合成令牌也不翻转此字段。CB-02 修改调用者原对象为 true 只是隔离负控，不改变快照或执行视图。

内建假执行器不是任意回调，只接受独立合成 expected 与 success/fail/throw 模式。expected 的有限字面差异只用于匹配器负对照，不驱动执行配置；prepare 仍固定型号、pinned 模式和六 GET 字面白名单。桥没有文件/环境/真实凭据加载、网络/子进程/监听或清理 API。依赖 checker 中的 `node:net.isIP` 仅作词法检查，不解析 DNS 或建立连接。

以上为静态代码核对；下节为真实 Node 进程的合成回归。它们都不同于 Windows 原生 ACL 检查。
