# 电脑端后台测试记录

## beta.14 小区与楼栋统一创建

新增 3 项测试，后台共 48 项：同一事务创建小区/楼栋、重复/无效输入不留下孤立小区、并发提交不重复。浏览器验证新小区带楼栋创建、选择已有小区追加楼栋、自动筛选到新楼栋，以及只读角色没有新增入口。原 1000 间生成流程仍通过。真实云事务未执行。

## beta.13 1000 间分批生成

新增 4 项测试，后台共 45 项：实际生成 1000 间并完整重放不覆盖旧记录、丢失响应后的重试补齐、1001 间和非法批次位置拒绝、异常批次响应不会循环。每批事务涉及记录最多 53 个（本地测试断言），避免将 1000 间塞进一个事务。浏览器在已有 6 间的场景，验证 1000 间预览后新增 994 间、总库存达到 1000。未经真实云端千间任务验收。

## beta.12 楼层与房间自动填充

新增 6 项测试，后台共 41 项。验证命名模板、起止范围、前缀/补零/地下层编号、排除项、超量拒绝、已有记录不覆盖、重复及并发提交、无效户型整批回滚。浏览器验证预览计数、跳过旧层、跨层生成和手动入口保留。未调用真实云环境，未使用智房管家内部接口或代码。

## beta.11 整栋物业与批量户型

新增 10 项模型/事务测试及 1 项 HTTP 权限/字段关联测试，后台共 35 项。浏览器新增小区、楼栋、楼层、户型、连续房号创建、批量设置户型与关联出租房源的验证，并检查只读账号没有写入口。云 SDK 多文档事务经模拟传输验证，未调用真实云环境。结构和截图见 [整栋物业说明](PROPERTY-MODEL.md)。

## beta.10 Windows 路径修复

用户在 Windows 启动成功后首页返回“文件不存在”。原因是静态目录检查将 Windows 路径与硬编码 `/` 拼接比较。已改为 path.relative / path.isAbsolute 校验，并使用 Node 的 path.win32 与 path.posix 验证首页、脚本、样式和图片路径及目录越界。新增 6 项路径测试，后台共 24 项测试通过。该验证运行在 Linux，模拟 Windows 路径规则；仍需用户 Windows 实际启动复验。

## 重现

```sh
npm test
npm run check
npm run test:admin
cd admin-web
npm ci
npm run test:sdk
npx playwright install chromium
npm run test:browser
```

已有 Chromium 时可通过 CHROMIUM_PATH 指定路径。浏览器测试使用临时数据，不修改开发演示数据；结束后清理，截图保留在 admin-web/test-results/。
