- README 同步改为 `device.manage`；
- 静态测试增加冻结权限白名单，禁止出现未定义的 `device.face.read`；

## P1-2：CDP 验证脚本不可跨环境复跑

`hk-ai-05a-cdp-verify.mjs` 把 Chrome 固定为 `C:/Program Files/Google/Chrome/Application/chrome.exe`，非 Windows 环境无法原样运行，并在 spawn 失败时触发未处理 error。

### 修复

- 优先读取 `CHROME_BIN`；未设置时按平台探测常见 Chrome/Chromium 路径；
- 找不到浏览器时输出明确错误并退出 1，不产生误导截图；
- 保留 Windows 默认路径兼容；
- README/检查文档补充 `CHROME_BIN=/path/to/chromium node ...` 用法；
- 不改变页面的零网络约束和既有验收断言。
