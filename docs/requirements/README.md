1. **押金相关对外入口、第三方支付入口暂不上线。** 旧押金模板与未来支付／72h留房／退款规则保留，不代表已取消政策；当前不收款、不伪造支付成功、不将无付款改成免押留房。预约与基础注册不依赖支付商户准备。
2. **获取开户码功能取消。** 用户页、`prepare`旧调用和后台开户码字段均列为代码改造项；当前固定 `.3` 代码仍含这些内容，本次仅改需求，不能说已经从包中移除。
3. **微信获取手机号成功后自动注册。** 服务端核验微信手机号凭证并使用可信微信身份创建／复用同一住户；拒绝授权、平台失败或身份歧义不得假注册。注册本身不授予房屋／设备权限，合法既有绑定另按服务端授权沿用。
4. 保留手机号及账号密码登录、管理员开通密码、最低8位。管理员针对已完成手机号注册的住户关联用户名／密码，不再使用开户码；不接受客户端自报手机号替代微信核验，不允许直接指定他人OPENID绑定。

这四项来自本轮用户明确消息，生效于需求范围；不修改已关闭v4或历史测试证据。现有代码与最新需求不一致的地方，明确进入[缺口清单](FUNCTION-GAPS.md)。
