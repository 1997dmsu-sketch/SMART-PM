# Windows 输入表单与明确确认：CLI 仍锁定

本阶段从 `1ebb86ea53872090a2bfcab89d1071538c221206` 接入 Windows Forms 输入及确认控件。实现包含真实交互模式，但本轮所有运行只使用合成种子、程序驱动控件和假传输；不收集真实凭据或照片，不连接设备。

## 代码入口

- `createWindowsInteractiveInputAdapter()` 仅接受空 options，创建时不启动进程、不显示窗口、不读取输入；不接受调用方替换 helper、审批回调、配置文件或传输。
- 与既有 `createWindowsPrivateInputPorts({adapter})` 配对后，经原有 bootstrap 读取输入。固定 Windows PowerShell 5.1 `-STA` helper 才构造原生表单。实际 `admin-web/face-readonly.mjs` 不安装这些端口或 runner，仍为 `LIVE_EXECUTION_LOCKED`。
- `createSyntheticWindowsInteractiveInputAdapter({seedBytes, action})` 是代码内离线测试入口，不是实际 CLI 的 JSON/argv/env 模式。种子立即复制、限 49152 字节；未指定动作默认拒绝。合成模式驱动同套表单控件和提交事件，不展示可供人填写的真实凭据窗口。

## 输入与确认

输入表单分别收集 HTTPS origin、用户名、遮罩密码、公开证书字节的 Base64、型号/计划号，以及独立核验的 pin、序列号、计划指纹、人数和目标员工/库号。它不自动填入历史连接配置，不读取证书文件、照片或凭据环境变量，不生成设备请求。公开证书 Base64 是公开证书文件字节的编码，不能填写私钥。

用户名和密码等字符串保留控件原文，不 trim 或文本管道重编码；校验失败不静默修正输入。提交后构造固定 `operation=list`、`mode=offline` 请求和独立预期字节，继续原有严格解析、私有不可变快照、证书 pin 及只读策略门禁。真实输入最多等待 240 秒；Node 外层 250 秒预算给取消和收尾留出余量，不把人工填写限制在业务 I/O 的 5 秒内。

确认页在所选证据接收方成功打开后出现；使用原生接收器时，继续要求其原生 ACL/文件门禁就绪。页面只读展示本次审阅视图和证据引用，密码、账号和证书内容不在确认页回显。默认不勾选确认且批准按钮禁用；必须勾选本次只读范围并明确点击批准。取消、关闭、未勾选、勾选后撤回或无决定均不批准；Enter 不是默认批准。一次提交、单次上下文与票据继续受原有品牌和生命周期限制。

确认响应仍逐项绑定 capture、challenge、精确视图字节和 evidence reference；helper 同时核对审阅字段与表单提交的快照。关闭 ACK、实际退出 0、无尾输出且无锁存失败之后，才允许转换为原有单次票据。确认页真实等待最多 25 秒，原有审批总预算最多 30 秒；超时或关闭失败停止，不延迟放行。

## 验证与边界

本轮合成控件测试覆盖同一输入/确认事件路径及其失败情形；原 1258 项另按既有命令回归。日志先保存真实 stdout/stderr/退出码，再解析统计；私密 helper stdout 不是公共日志，不保存到交付日志中。原字节源码快照、前后哈希、负控副本和全部合成对象保留，不清理。

程序驱动真实控件不等于真人已输入、已阅读或已点击，也不等于 Windows 身份认证。本轮未人工操作真实交互模式，未核验辅助技术、桌面锁定/RDP 状态、所有焦点/键盘情形或长期运行表现。不得将这些未验项写成通过。

同机同信任域、管理员/内核和受信任代码改写边界、Promise 构造器/原型边界、文件阶段检查至使用间及句柄释放后的 TOCTOU 边界继续保留。有界失败不能保证异常系统中的进程必已退出；未观察到正常退出不得补写 0。可变字节和控件引用收尾清理不保证 .NET/JavaScript 不可变字符串及运行时副本物理擦除。

这不是实际 CLI 解锁或 E1/E2 放行。真实 TLS、网络、设备身份、当前人数和 `F03FF8DA7299CE148` 入库状态仍未验；后续须另行复审与单次实机只读授权。本轮实施证据见 `docs/evidence/hk-face-management/READONLY-WINDOWS-INTERACTIVE-INPUT-2026-11-29.md`。
