## 视觉与素材规则

- 主色采用近似设计值 `#ff2450`，白色卡片，浅灰背景，个人/开门区域粉色渐变。
- 顶部状态栏由系统提供，不绘制固定的 9:41、电量或信号。
- 自定义导航避让微信原生右上角胶囊；相关按钮移位是实际运行适配。
- 底部为首页、广场、居中开门、消息、我的五个入口；开门按钮突出。
- 弹窗、详情操作栏、TabBar 均考虑底部安全区域。
- 原切图选取所需尺寸拷入运行目录；整页设计图不打进小程序包。
- 演示房源/内容照片从本次截图的纯照片区域提取，位于 `assets/design/`；
  页面标题、卡片、按钮、列表和弹窗均为原生组件，而非整页截图点击热区。
- 照片当前仅用于设计演示，真实模式使用后端图片；这不代表已取得商用素材授权。

| 交互 | 当前行为 | 旧后端对应 |

## 后端复用中发现的具体缺口

- `phoneLogin/index.js` 回填房屋后使用未定义变量 `houses` 计算 `bound`，会进入捕获逻辑；
  此历史问题已在 beta.8 修复并加入回归测试；beta.9 进一步保留网页管理后台手动维护的房产绑定。
- `meterService` 返回账号设备列表，未见住户上下文与房产权属校验；新前端默认不接通该读取。
- 缺少房源按 ID 详情、预约提交、住户家庭成员、住户房产详情、设备管理等接口。
- 后端复制文件的完整性校验保持不变，上述问题不通过修改来源记录来掩盖。
