## 1. 开拍前硬性检查

- [ ] 完整门禁机型号/后缀、固件和背部端子已双人读清。
- [ ] PDC-K7B-12V5A 绿色端子排正面垂直照片清晰，丝印无反光、遮挡和失焦。
- [ ] 门锁铭牌的供电电压、电流、断电开门/通电开门属性已双人确认。
- [ ] 已取得对应实物说明书；没有拿软件 ISAPI 文档充当物理端子说明。
- [ ] 220 V 作业、断电、验电、测量和恢复供电均由具备相应能力的现场人员执行。
- [ ] 上锁挂牌、防止误送电、绝缘防护、人工开门与消防疏散预案已落实。
- [ ] 门区无无关人员，测试门可安全固定，断电测试不会造成人员受困或疏散风险。
- [ ] 测试人脸已获授权且只在画外使用；画面只拍结果，不采集真实人脸镜头。
- [ ] 屏幕、铭牌和贴纸不含密码、内网地址、序列号、MAC、二维码、完整证书指纹或住户信息。
- [ ] 两名复核人：________／________；拍摄人：________；现场负责人：________。

**任一不符合，停止拍摄施工镜头，只保留问题照片并登记待确认项。**

## 2. 拍摄与叠加统一要求

1. 主片横屏 1920×1080；建议 25 fps，快门、白平衡和曝光固定，端子特写不得依赖数码放大补救失焦。
2. 端子排使用垂直俯拍/正面近摄，另拍一张带设备整体的环境照。每根线的线号与对应丝印要同时可读。
3. 每个接线镜头都有五项信息条：`端子名｜线号｜输入/输出类型｜电压｜断电状态`。未确认字段写“待真人确认”，不得留成误导性空白。
4. 首次通电、六项验收使用连续镜头；保留开始、操作、结果和读数，不用跳剪制造成功结果。
5. 禁止拍摄带电剥线、短接、插拔端子、反接演示、过载演示或用电流档跨接电源。
6. 每镜头开头拍 2 秒场记板：`HK02 / 镜头ID / take编号 / 断电状态 / 拍摄人`。场记板不含真实位置或人员信息。
7. 文件命名：`V##_CAMA_take##`、`V##_CAMB_take##`；照片用 `EVIDENCE_类别_序号`，不使用住户姓名、房号或真实设备标识。
