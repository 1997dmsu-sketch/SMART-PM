# 手机号自动注册与取消开户码：实现记录

日期：2026-11-25（Asia/Shanghai）。基线 `58609bbcfad4948cc21ea8fc06929c0f36fadef5`；
分支 `fix/phone-auto-register-no-opening-code-2026-11-25`；版本 `0.1.0-beta.20-phone-register.2`。

## 最终行为

- 小程序不再提供生成、复制或提交开户码的入口；后台不再消费开户码。旧 `prepare` 请求拒绝，
  历史数据和报告保留，不做删除或自动迁移。
- 用户在「我的」授权微信手机号，服务端核验临时凭证后自动注册或复用同一住户。
  不接受客户端自报的手机号、userId 或 OpenID；取消授权不注册。
- 手机号私有证明、canonical 身份与用户更新在同一事务内提交；同一微信重复请求复用住户，
  不同微信争用同一手机号只有一个成功。查询错误、身份损坏及已有不同手机号失败关闭，
  不自动换号、转户、合并房屋或导入 owners 权限。
- 管理员只为已完成可信手机号注册的现有住户开通密码。密码登录仍要求当前微信及手机号证明
  匹配；缺少证明的历史住户重新授权同一手机号后可继续使用原账号及合法房屋绑定。
  保留八位最低密码、scrypt、持久限速、CAS、管理员权限和审计。
- 手机号与密码登录共享资料白名单、安全提示和请求代次保护，离页、退出及迟到回包不恢复认证。
- 管理后台 live 租客账号分支采用专用 CloudBase 管理 SDK 适配器；微信云函数协议保持原样。

## 部署前条件与限制

`tenant_auth_phone_bindings` 等认证集合须禁止客户端读写；users 的手机号、验证时间、身份及
房屋权限字段须由可信服务端维护。微信手机号 API 权限、额度、目标数据库索引、事务能力及规则
需在目标环境核验；四份身份 helper 和两份手机号证明 helper 必须一致发布。

本轮没有部署、上传体验版、创建真实账号、真实微信授权、访问业务云、支付或设备操作。
未执行 `verify-import.mjs` 的依赖加载阶段，也未重新验收旧设备、完整Windows ACL或完整CLI。
因此仅交付实现、离线回归与代码复核；既有上传、部署和真实验收冻结不因本记录解除。
