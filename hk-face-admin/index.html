本轮范围与边界

feat/hk-face-admin · HK-AI-05A
  • 五页首屏均持续显示统一 Mock 横幅（executionMode=test / provider=mock / evidenceScope=simulated / 真实设备生效：否），打印态保留。
  • 四业务页提供六类合成状态（loading / empty / forbidden / error / retrying / ready），仅切换合成 UI 状态，刷新恢复默认，不读取浏览器本地存储，不发网络请求。
  • 合成记录一律使用 DEMO 前缀代号，不含任何真实人员信息或真实硬件标识；私密内容仅以「需逐次授权查看」占位表达，不加载任何图片、外链或字节。
  • 未知结果（UNKNOWN_RESULT）只允许查询 / 人工对账，不提供重复下发，系统自动重试禁用；受控重试仅在 retryable 状态且具备 device.operation.retry 时可操作。
  • 审核权限（device.face.review）不自动获得私密读取权限（device.face.readPrivate）；缺失权限时显示 forbidden 状态。
  • 未接入真实 API、真实数据、真实门禁设备、Provider、登录权限体系；未实现真实文件读取或下载；未合并 main。
