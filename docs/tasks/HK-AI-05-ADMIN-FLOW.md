优先级：P1
执行者：Workburry
复审者：Codex
基准：HK-AI-04 API 契约冻结提交
建议分支：`feat/hk-face-admin`

真人任务依赖：无；可先基于 Mock 开发。

## 快速上线范围

首批由管理员后台提交和审核人脸，住户小程序自助录入延后。页面必须显著展示 `Mock`、隔离测试和真实灰度状态。

## 页面

1. 海康设备列表、型号、固件、能力状态和灰度状态。
2. 人脸申请列表、详情、同意记录、审核、拒绝、撤销和补件。
3. 私密人脸图片逐次授权查看，审核权限不自动包含原图读取权限。
4. 人员、房间、入住周期、设备和授权有效期选择。
5. 操作任务列表、状态、尝试次数、最后错误、未知结果人工对账和受控重试。
6. 退租未撤权、设备离线、任务积压和删除失败告警。
7. 不可变操作审计查询。

## 权限

- `device.manage`
- `device.face.review`
- `device.face.readPrivate`
- `device.operation.retry`
- `device.audit.read`

## 禁止事项

- 不直接从浏览器访问设备 IP。
- 不返回设备账号、密码、序列号、厂商内部凭据或永久人脸 URL。
- 不允许对未知结果直接点击“再次新增”；必须先查询/人工对账。
- 不提供“删除全部人脸库”按钮。

## 验收

- 无私密读取权限的审核员看不到原图。
- 无重试权限不能操作任务。
- 每个批准、拒绝、查看原图、重试和撤销均有理由及审计。
- Mock 状态不会伪装成真实设备生效。
