## 发现并关闭的问题

1. 父 shell 若遗留 `HIKVISION_PROBE_ALLOW_READ=true`，原脚本的第一条 `node cli.mjs` 会跳过 dry-run 并直接联网。现已在 dry-run 前显式 `unset`，并增加变量不存在断言。
2. 父 shell 遗留 `HIKVISION_PROBE_CA_PEM`、超时或响应上限可能改变批准参数。现已强制指纹模式，固定 `10000ms / 262144 bytes`，退出时清理。
3. 已确认目标端口必须非空纯数字，且 `ALLOWED_PORTS` 只包含本次批准端口。
4. dry-run 非0时不能进入真实执行；真实执行退出码原样返回。
5. 专用输出目录可确定定位和删除，父 shell 的 umask 不被改变。
