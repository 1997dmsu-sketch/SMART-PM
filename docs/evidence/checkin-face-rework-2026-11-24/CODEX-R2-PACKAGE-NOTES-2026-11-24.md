## 生成源码测试包

从干净且已提交的代码执行：

```text
python scripts/package-release.py --live --checkin-face
```

也可执行 `npm run release:checkin-face`。本profile先强制静态/来源门禁，再在实际解压的源码内运行全部根合成测试、聚焦后台/worker测试、小程序结构检查及归档安全测试，禁止业务网络/监听。它与旧完整profile分开，旧HTTP全量流程未删除或冒充执行。

产物包括源码ZIP、SHA256SUMS、test-report.txt与release-manifest.json。仅从Git提交归档，拒绝本地秘密、node_modules、缓存、路径穿越、Windows别名/重复路径和符号链接。任何检查失败不生成成功包。
