# HK 人脸门禁管理后台 · 页面壳

分支：`feat/hk-face-admin`（独立 git 仓库，与 `SMART-PM` / `mini-shop` 完全隔离）

## 一、本轮交付

| 文件 | 说明 |
| --- | --- |
| `index.html` | 概览 / 导航中枢，列出 4 个业务模块与交付边界 |
| `devices.html` | 设备管理：台账、点位、在线状态、固件版本 |
| `applications.html` | 申请管理：通行权限与人脸采集授权审批 |
| `tasks.html` | 任务中心：设备下发、人脸库同步等异步任务 |
| `audits.html` | 审计日志：通行记录、管理操作、安全事件留痕 |
| `styles.css` | 共享样式（含响应式与打印样式） |
| `app.js` | 共享交互：导航高亮、按钮占位提示、筛选重置 |

四个业务页面壳均包含：统一侧边栏与顶栏、页面标题与操作区、4 张统计卡、领域筛选条件、领域表格列结构、空状态、分页占位。

## 二、如何打开

直接用浏览器打开 `index.html` 即可（`file://` 双击可用），无需安装依赖、无需启动服务、无需联网。

- 零第三方依赖、零框架、零 CDN / 外链；
- 仅引用同目录的 `styles.css` 与 `app.js`；
- 支持打印（打印时自动隐藏侧边栏、操作按钮与筛选栏）。

## 三、明确边界（重要）

本轮**只做页面壳**，以下均**未实现**，请勿按可用系统评估：

1. 未接入任何真实 API、真实数据或真实人脸门禁设备；统计值统一为 `—`，表格为空状态，不代表任何真实指标。
2. 未做真实设备硬件联调 —— 这是项目可用的必要前置环节，不在页面壳范围内。
3. 未实现登录、身份认证、角色权限、组织隔离、审计落库。
4. 按钮 / 链接点击只弹出「功能待接入」占位提示，不产生任何网络请求或写操作。
5. 未做 API 文档整理（工期需按实际接口数量与文档页数核定后再承诺）。
6. 未创建定时任务、未接入企业微信同步、未发布公网在线链接。
7. 未复用业主端小程序画板布局：既有设计稿是 375×812 的业主端小程序，本后台只借用颜色 / 字号 / 圆角等设计 token。
