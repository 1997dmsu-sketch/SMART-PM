## 当前验收基线

- 项目总控表初始包含 **19 项前置、92 条用例、48 类证据**；当前为 **19 项前置未完成、92 条用例未执行、有效证据 0**，交付结论为 **“前置未完成”**。
- **CORE-01** 的“在线签约 → 签约后录入人脸 → 授权开门”为必须跑通的核心链路，目前尚无端到端实现与验收证据；单一环节成功不能判定全链路通过。
- **TEN-04** 已确认 P1 优先顺序，但具体业务规则仍待确认，不能据用例表认定业务已完成。
- 原分表与项目总控表是相互独立的副本，不会自动同步；后续执行统一以项目总控表为准。

## Codex 复审重点

1. 对照 `docs/requirements/` 检查最新用户决策是否完整落入实现计划，尤其是无开户码注册、全体管理员预约处理、CORE-01 和 TEN-04。
2. 检查代码现状与需求文档的差异，不将旧离线测试、代码片段或本机草稿视为现网可用证据。
3. 检查 CORE-01 的身份、房屋、合同、租期、人脸与设备授权是否由同一服务端事实链串联，并覆盖撤销、过期、重复请求和失败回退。
4. 检查报修保洁、MKT-01、OPS-05 及支付入口是否按当前范围保持未开放，避免旧入口被误当作本期交付能力。
