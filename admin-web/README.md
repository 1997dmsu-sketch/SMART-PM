# 宇宙物业智联 · 电脑端管理后台

后台版本 `0.1.0-beta.1`，随项目 `v0.1.0-beta.9` 交付。

## Windows 上快速体验

1. 安装 Node.js 20 或更新的 LTS 版本。
2. 解压项目，进入 `admin-web` 文件夹，双击 **start-demo.cmd**。
3. 保持命令窗口打开，在浏览器访问 **http://127.0.0.1:4173**。
4. 点击“进入演示工作台”。演示模式无需安装依赖，也无需云账号。

也可以在此目录运行 `npm start`。这是独立网页服务，**不要在微信开发者工具中编译这个目录，也不要直接双击 index.html**。

演示修改持久保存在 `.data/demo/`，重启不会清空；它们与小程序的 `services/demo.js` 以及真实云数据库分别独立。关闭命令窗口即可停止服务。

## 本期功能

- 工作台：房源、用户、内容、房产统计及最近操作。
- 房源：搜索、分页、编辑、封面上传、租金、上下架。
- 内容：草稿、发布、撤回、图片上传、正文和预览。
- 用户：查询微信用户、维护姓名、绑定或解绑房产。
- 房产：维护房产档案，固定唯一 houseId。
- 权限：系统管理员、内容运营、只读成员；账号创建、停用、密码重置和本人改密。
- 日志：业务修改与后台账号变更记录。

第二期手机管理端将使用同一套 `/api` 接口；本期验收以电脑端为准。

## 接入真实数据与部署

详见仓库中的 [docs/ADMIN-WEB.md](../docs/ADMIN-WEB.md)。真实模式需要在服务端配置云访问凭据、创建独立后台管理员，并准备 `admin_audit` 集合。本次未执行真实云连接或部署。

## 开发检查

```sh
npm test
npm ci
npm run test:sdk
npx playwright install chromium
npm run test:browser
```

浏览器检查会自行启动独立临时演示服务并清理数据，截图输出到忽略提交的 `test-results/`。如已有 Chromium，可设置 `CHROMIUM_PATH` 为浏览器路径。`test:sdk` 使用真实安装的 SDK 和模拟传输，不发出云请求。
